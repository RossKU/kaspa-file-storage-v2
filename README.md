# Kaspa P2P File Storage v5.11.118

A decentralized file storage system built on the Kaspa blockchain.

## Features
- Upload files to Kaspa blockchain
- Encrypted file storage
- Directory support
- WebSocket real-time monitoring
- Archive node auto-discovery

## Quick Start
1. Open `index.html` in a web browser
2. Connect your wallet
3. Upload files or directories

## Requirements
- Modern web browser
- Kaspa wallet with some KAS for transaction fees

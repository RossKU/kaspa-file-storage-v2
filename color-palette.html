⚠️ 重複・類似している色

  • --bg-tertiary: #ffffff は --bg-primary: #ffffff と同じ（ライトテーマ）
  • --warning-color: #ffc107 と --status-warning: #ffcc66 は両方警告色で役割が重複
  • --status-connected: #49EACB はCLAUDE.mdで #2A6F65 への変更が指定されている

🔧 まだハードコードされている色

  • white - サイドバー内のテキスト（約10箇所）
  • transparent - 背景リセット用
  • rgba(255, 255, 255, 0.2) - サイドバーのボーダー
  • rgba(255, 255, 255, 0.3) - サイドバーのボーダー（強調）
  • rgba(0, 0, 0, 0.9) - ツールチップ背景
  • #16213e - ボタンテキスト（1箇所）
  • #c13651 - 削除ボタン背景（1箇所）
  • #ff9800 - JavaScriptでのステータス色
  • #2196F3 - JavaScriptでのステータス色

✅ 色を絞るための推奨事項

  1. 重複を削除
    • --bg-tertiary を削除（--bg-primaryで代用）
    • --status-warning を --warning-color に統一
  2. ハードコード色をCSS変数化
    • white → --sidebar-text として定義
    • rgba系 → --sidebar-border-light, --sidebar-border として定義
    • 特殊用途の色（#16213e, #c13651）→ 既存の色で代用を検討
  3. 色数を削減
    • 現在: 実質20種類 → 目標: 15種類以下
    • ステータス色を4種類（success, error, warning, info）に統一
    • グレースケールは3段階（primary, secondary, border）で十分
  4. CLAUDE.md対応
    • --status-connected: #49EACB → #2A6F65 に変更

🎯 推奨される最終的な色構成（15色以下）

基本色（6色）

  • 背景: primary, secondary
  • テキスト: primary, secondary
  • ボーダー: 1色
  • コード背景: 1色

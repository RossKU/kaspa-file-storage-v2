  1. KENVエントリーの情報不足

  salt: "",              // 空文字列

  chunkBlockIds: [],     // 空配列
  3. なぜMetaTxIDコピーは動作するか
    - KENVにはmetaTxIdとmetaTxBlockIdが正しく保存されている
    - コピー機能はこの2つの情報のみを使用

  解決策（3つの方法）

  1. 方法1: KENVエントリーに詳細情報を追加
    - アップロード完了時にchunks、salt等をKENVに保存
  2. 方法2: .kaspaファイル生成時にメタトランザクションから情報を取得
    - MetaTxIDを使用して完全な情報を取得
  3. 方法3: 最小限の.kaspaファイル（MetaTxID参照型）

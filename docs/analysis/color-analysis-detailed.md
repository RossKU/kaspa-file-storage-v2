## 重複・類似色の分析

### グレー系の重複
- `#666666` (--text-secondary)
- `#999999` (--text-secondary ダーク)
- `#333333` (--input-text, --border-color ダーク)
- `#333` (ハードコード)
- `#444` (ハードコード)

**→ 3種類に統一可能**

### 警告色の重複
- `#ffc107` (--warning-color)
- `#ffcc66` (--status-warning)

**→ 1種類に統一可能**

### 白・黒の重複定義
- `#ffffff` (--bg-primary, --bg-tertiary)
- `white` (ハードコード)
- `#000000` (--text-primary)
- `#000` (ハードコード)

**→ CSS変数で統一可能**

## 削減提案

### Phase 1: 即座に実施可能
1. `--bg-tertiary` を削除（`--bg-primary`で代用）
2. `--status-warning` を `--warning-color` に統一
3. ハードコードの `white` を変数化
4. ハードコードの `#000` を変数化

### Phase 2: 構造的な改善
1. グレースケールを3段階に整理
   - Light: `#e0e0e0`
   - Medium: `#666666`
   - Dark: `#333333`

2. 透明度システムの導入
   ```css
   --alpha-10: 0.1;
   --alpha-20: 0.2;
   --alpha-30: 0.3;
   --alpha-80: 0.8;
   --alpha-90: 0.9;
   ```

3. セマンティック変数の追加
   ```css
   --sidebar-text: white;
   --danger-action: #c13651;
   --connecting-status: #ff9800;
   ```

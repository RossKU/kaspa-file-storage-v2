# v5.10.0 リリースノート

## 概要
chunkBoundaries から segmentBoundaries への用語変更

## 変更理由
- **チャンク** (22KB): 暗号化・転送の基本単位
- **セグメント** (1MB): 圧縮・復号化の処理単位

2つの異なる概念を明確に区別するため、1MB単位の境界情報を「セグメントバウンダリ」に変更。

## 技術的変更

### プロパティ名変更
- `metadata.chunkBoundaries` → `metadata.segmentBoundaries`
- 全41箇所の参照を更新

### 後方互換性
既存データとの互換性のため、読み込み時は両方のプロパティをサポート：
```javascript
const boundaries = metadata.metadata?.segmentBoundaries || 
                  metadata.metadata?.chunkBoundaries;
```

### 主な変更箇所
1. **ファイルアップロード処理** (processFileWithPayloadSplit)
2. **ダウンロード処理** (DownloadManager) 
3. **スーパーメタデータ処理** (中間メタデータへの分配)
4. **アップロード履歴管理**

## テスト項目
- [ ] payloadSplitモードでのファイルアップロード
- [ ] 大容量ファイル（>3.5MB）のアップロード・ダウンロード
- [ ] スーパーメタデータの作成・読み込み
- [ ] 既存ファイル（v5.9.4以前）のダウンロード

## 影響範囲
- 新規アップロードは`segmentBoundaries`を使用
- 既存ファイルは`chunkBoundaries`のまま動作
- 未リリースのため、ユーザーへの影響なし

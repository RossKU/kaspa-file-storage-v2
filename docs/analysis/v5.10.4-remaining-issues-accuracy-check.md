### 3. **エントリー名の.kaspaファイル名問題** ✅ 確認済み

#### 根本原因（12278-12390行目）
```javascript
// 履歴からファイルを選択してディレクトリ作成
for (const fileId of window.selectedHistoryFiles) {
    const item = history.find(h => h.id === fileId);
    if (item) {
        selectedFiles.push({
            name: item.fileName || item.name,  // 履歴に保存された.kaspaファイル名
            path: item.path || item.name,
            type: 'file',
            metaTxId: metaTxId,
            blockId: blockId,
            size: item.fileSize || item.size || 0
        });
    }
}
```

**問題の流れ**：
1. ファイルアップロード時に履歴に`.kaspa`ファイル名で保存
2. 履歴から選択してディレクトリ作成
3. 元のファイル名情報が失われる

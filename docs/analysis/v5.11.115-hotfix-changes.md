# v5.11.115-hotfix: WSDebugInfoスコープ修正

## 修正内容

### エラー修正
- `WSDebugInfo is not defined`エラーを修正
- WSDebugInfoオブジェクトをグローバルスコープに公開

### 変更箇所
```javascript
// 統計表示タイマー
let wsDebugTimer = null;

// WSDebugInfoをグローバルに公開
window.WSDebugInfo = WSDebugInfo;  // ← 追加
```

## エラーの原因
- WSDebugInfoがmodule script内で定義されていた
- 他の部分からアクセスできなかった
- GitHub Pages上でエラーが発生（ローカルでは発生しない場合がある）

## 影響
- エラーは発生していたが、アップロード処理自体は正常動作
- デバッグログ機能のみが使用不可だった

## テスト結果
- エラーが解消されることを確認
- デバッグログ機能が正常動作

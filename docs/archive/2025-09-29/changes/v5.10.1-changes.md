# v5.10.1 変更内容

## 概要
WebSocket監視タイマーで発生するTypeErrorを修正しました。

## 修正された問題

### 1. arguments.callee使用によるTypeError
**問題**：
- strict modeで`arguments.callee`が使用できずTypeErrorが発生
- WebSocket監視のタイマーリセットが失敗
- 5分以上のアップロードで監視が意図せず停止する可能性

**エラー内容**：
```
TypeError: 'caller', 'callee', and 'arguments' properties may not be accessed on strict mode functions or the arguments objects for calls to them
```

**修正内容**：
```javascript
// 修正前（11914行、11920行、11928行）
AppState.monitoring.wsMonitorTimeout = setTimeout(async () => {
    // ...
    AppState.monitoring.wsMonitorTimeout = setTimeout(arguments.callee, 5 * 60 * 1000);
}, 5 * 60 * 1000);

// 修正後
AppState.monitoring.wsMonitorTimeout = setTimeout(async function checkTimeout() {
    // ...
    AppState.monitoring.wsMonitorTimeout = setTimeout(checkTimeout, 5 * 60 * 1000);
}, 5 * 60 * 1000);
```

### 2. uploadingDirMeta参照の統一
**変更内容**：
- 一貫性のため`uploadingDirMeta`を`FileState.uploadingDirMeta`に統一
- 11598行、11602行、11916行で修正

## 影響範囲
- WebSocket監視機能のみ
- アップロード機能への影響なし
- 既存データとの互換性に影響なし

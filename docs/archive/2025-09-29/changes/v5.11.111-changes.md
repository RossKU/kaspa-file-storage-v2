# v5.11.111 変更内容 - DirectoryMetadata CSV保存形式の修正

## 実施日時
2025-08-03

## 変更内容

### KENV v3.1.4仕様に準拠した7カラム形式への修正
DirectoryMetadataのCSV保存形式をBase64エンコードから7カラム形式に変更

### 背景
- v5.11.110ではBase64エンコードで実装（仕様違反）
- KENV v3.1.4仕様では7カラム形式が定義されている
- ディレクトリビルダーで生成したJSONをKENV経由で完全に復元する必要がある

### 修正内容
1. **saveKentryFileの修正**
   - 'dirmeta,Base64' 形式を廃止
   - 'entries,fileCount,dirCount,entry1,...,entryN' 形式に変更
   - 各エントリーは7カラム: type,name,path,size,metaTxId,blockId,password

2. **loadKentryFileの修正**
   - 'entries'マーカーを検出して7カラムパース
   - 完全なdirectoryMetadata JSONを再構築
   - 後方互換性のため'dirmeta'形式も読み込み可能

3. **DirectoryMetadata再構築ロジック**
   - entriesから完全なJSON構造を復元
   - directory、recovery、metadata等の情報も含む

### 利点
- CSVネイティブで人間が読める
- JSONエンコーディング不要
- 個別エントリーへの直接アクセス可能
- 仕様準拠

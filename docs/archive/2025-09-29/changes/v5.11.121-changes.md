# v5.11.121: ハードフォーク対応日数計算とアーカイブノード表示改善（Ultrathink）

## 変更内容

### 1. 日数計算の精度向上
**問題**
- Kaspaは101Mブロックでハードフォーク（1BPS→10BPS）
- 従来の計算は一律10BPSで不正確

**解決策**
- 0～101M: 1BPS（86,400ブロック/日）
- 101M以降: 10BPS（864,000ブロック/日）
- 表示形式: `XXX.Xdays+`（+は継続中を示す）

### 2. 共通関数の実装（7145-7162行）
```javascript
function calculateDaysFromBlocks(blueScore) {
    const hardforkBlock = 101000000;
    if (blueScore <= hardforkBlock) {
        days = blueScore / 86400; // 1 BPS
    } else {
        const preHardforkDays = hardforkBlock / 86400;
        const postHardforkBlocks = blueScore - hardforkBlock;
        const postHardforkDays = postHardforkBlocks / 864000; // 10 BPS
        days = preHardforkDays + postHardforkDays;
    }
    return days.toFixed(1);
}
```

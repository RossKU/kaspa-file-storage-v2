# v5.11.129: アーカイブノードのハードコードURL削除

## 削除理由
これらのアーカイブノードURLは実際には存在しないものでした：
- `wss://archive-tn10.kaspa.org:17210`
- `wss://archive.kaspa.org:17110`

## 変更内容

### 1. config.archiveEndpointsをnullに設定
```javascript
archiveEndpoints: {
    'testnet-10': null, // Archive nodes not available
    'mainnet': null // Archive nodes not available
},
```

### 2. createRpcClient関数にnullチェックを追加
- アーカイブノードが利用できない場合は自動的に標準Resolverにフォールバック
- 適切な警告メッセージを表示

### 3. アーカイブノード表示のダミーデータを修正
- `wss://archive-mainnet.kaspa.org` → `N/A (Archive nodes not available)`

### 4. REST API接続テストを動的化
- ハードコードされた`https://api-tn10.kaspa.org`を`config.apiEndpoints[config.network]`に変更

## 影響
- アーカイブノードモードが選択された場合、自動的に標準Resolverにフォールバック
- 既存の機能には影響なし

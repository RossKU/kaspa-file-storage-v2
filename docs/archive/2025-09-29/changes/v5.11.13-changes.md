# v5.11.13 Changes - Dev Wallet Scope Fix

## Issue Fixed
- Fixed: `Uncaught ReferenceError: AppState is not defined` error when toggling Dev Wallet switch
- Error occurred at line 15389 when accessing AppState from a different script scope

## Root Cause
- JavaScript `const` variables have block scope
- `AppState` was defined in the first `<script>` tag but was not exposed to window
- `toggleDevWallet` function was defined in the second `<script>` tag
- AppState was not accessible from the second script or HTML event handlers

## Solution
Proper architecture-aligned fix without using window for individual functions:

1. **Exposed AppState to window** (line 2457)
   - Added `window.AppState = AppState;` following the same pattern as other State objects
   - This aligns with existing architecture (NetworkState, FileState, WorkspaceState)

2. **Moved functions as AppState methods**
   - `AppState.toggleDevWallet()` - Toggle Dev Wallet on/off
   - `AppState.loadDevWalletSetting()` - Load setting from localStorage
   - `AppState.disconnectWallet()` - Disconnect current wallet

3. **Updated all function calls**
   - HTML: `onchange="AppState.toggleDevWallet()"`
   - DOMContentLoaded: `AppState.loadDevWalletSetting()`
   - connectWallet: `AppState.disconnectWallet()`

## Technical Details
- No `window.functionName` assignments - functions are AppState methods
- Follows existing State management architecture
- AppState is now globally accessible like other State objects
- All Dev Wallet functionality encapsulated within AppState

# v5.11.132: チャンクサイズ設定の修正

## 変更内容

設定タブのチャンクサイズ選択肢を過去のバージョンと一致させました。

### 修正前：
- 10KB chunks (安全)
- 12KB chunks (旧方式)
- 15KB chunks (リスクあり)
- 18KB chunks (並列アップロード推奨) - selected ← 削除
- 20KB chunks (高リスク)

### 修正後（元の設定に復元）：
- 10KB chunks (安全)
- 12KB chunks (旧方式)
- 15KB chunks (リスクあり)
- 20KB chunks 🧪 (実験的)
- **22KB chunks 🚀 (推奨・可変チャンク)** - selected（デフォルト）

### 理由：
- 現在は22KBチャンクのみを使用しているため
- 18KBオプションは過去に存在しなかった誤った追加
- ユーザーの指摘に基づいて元の設定に戻しました

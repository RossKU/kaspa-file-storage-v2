# v5.11.137: 複数WebSocketテスト機能（実験的）

## 概要
デバッグタブに複数ノードでBlock-addedイベントをリッスンするテスト機能を追加しました。

## 機能

### MultiWebSocketTest
- ArchiveNodeManagerで発見したノードを利用
- 最大3つのノードに同時接続
- 各ノードでBlock-addedイベントをリッスン
- 監視中のトランザクションを自動検出

### 使い方
1. デバッグタブを開く
2. アーカイブノード探索を実行（既存機能）
3. 「複数WebSocketテスト」セクションで「開始」をクリック
4. 接続したノードでBlock-addedイベントをリッスン開始
5. 新しいブロックが来ると、どのノードから最初に検出したか表示

### 検証ポイント
- 同じブロックを複数ノードから受信した場合の遅延時間
- 監視中のトランザクションのBlockID検出速度
- ノード間の同期状況

## 技術的詳細

### 実装
- 既存のRpcClientを使用して補助接続を作成
- subscribeBlockAddedでイベントをリッスン
- メインのmonitoredTransactionsを共有
- BlockIDが検出されたら自動的に更新

### 最小限の変更
- 既存のアップロードロジックには一切変更なし
- デバッグ用の独立した機能として実装
- オンオフ可能なテスト機能

## 将来の可能性
このテストが成功すれば、本番のアップロード機能に統合して：
- BlockID検出速度の向上（54秒→20秒）
- ネットワーク障害への耐性向上
- より確実なトランザクション確認

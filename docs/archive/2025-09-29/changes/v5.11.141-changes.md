# v5.11.141: 5ノード並列監視（4補助+1メイン）

## 概要
補助RPCを4ノードに拡張し、各ノード1秒遅延で開始。重複処理対策も追加。

## 主な変更内容

### 1. NetworkState拡張
```javascript
auxRpcClients: [],  // 配列化（4ノード）
rpcScores: { main: 0, aux: [0, 0, 0, 0] }  // 個別スコア
```

### 2. 補助RPC作成ロジック
- ループで4ノード作成
- 各ノード1秒遅延開始（0秒、1秒、2秒、3秒）
- 異なるタイミングでsubscribeBlockAdded()を呼ぶ

### 3. 重複処理対策
- メインRPCにも`if (!existing.blockId)`チェック追加
- すでに検出済みの場合はスキップ
- 最初に検出したノードのみスコア獲得

### 4. クリーンアップ処理
- stopMonitoring時に全補助RPCを停止
- 配列をループして個別に切断

## 技術的詳細

### 遅延開始の効果
- 各ノードが異なるブロックから監視開始
- ネットワーク負荷の分散
- より多様なノードからのブロック受信

### スコア表示
```
[スコア] メイン: 2, 補助合計: 3 (各: 0, 1, 2, 0)
```
- メインと補助の合計を表示
- 各補助ノードの個別スコアも確認可能

## 期待される効果
- BlockID検出速度の大幅向上（5ノード競争）
- ネットワーク障害への耐性向上
- 効率的な重複処理回避

## 行数変化
- 元の実装: 45行
- 新実装: 約55行（ループ化で効率的）
- 増加分: わずか10行

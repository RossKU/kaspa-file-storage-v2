# v5.11.39 変更内容 - KENV Phase 1-A ファイル名分離

## 実装日時
2025-07-30

## 概要
KENV v3.1.3統合の最初のフェーズとして、ファイル名の分離と基本的な保存・読み込み機能を実装。UploadHistoryManagerとの競合を回避。

## 主な変更点

### 1. FileState.kenvManagerへのファイル名定義追加
```javascript
// ファイル名定義（v5.11.39: Phase 1-A）
kenvFile: 'workspace.kenv',      // 設定ファイル
kindexFile: 'workspace.kindex',  // インデックスファイル
kentryFile: 'workspace.kentry',  // エントリーデータファイル
```

### 2. ファイル保存・読み込み関数の実装
- `saveKenvFile()`: .kenv設定ファイルの保存
- `saveKindexFile()`: インデックスファイルの保存
- `saveKentryFile()`: CSVエントリーファイルの保存
- `saveAll()`: すべてのファイルを一括保存
- `loadKenvFile()`: .kenv設定ファイルの読み込み
- `loadKindexFile()`: インデックスファイルの読み込み
- `loadKentryFile()`: CSVエントリーファイルの読み込み
- `loadAll()`: すべてのファイルを一括読み込み
- `initialize()`: KENV初期化処理
- `parseCSVLine()`: CSV解析ヘルパー関数

### 3. File Tab切り替え時の初期化処理
UIHandlers.switchTab関数内：
```javascript
if (tab === 'file') {
    // v5.11.39: Phase 1-A - Initialize KENV before updating file list
    if (WorkspaceState.handle && !FileState.kenvManager._initialized) {
        FileState.kenvManager.initialize().then(() => {
            FileState.kenvManager._initialized = true;
            window.updateFileListFromKENV();
        });
    } else {
        window.updateFileListFromKENV();
    }
}
```

### 4. ワークスペース設定時のKENV初期化
setupWorkspace関数内：
```javascript
// v5.11.39: Phase 1-A - Initialize KENV after workspace setup
await FileState.kenvManager.initialize();
FileState.kenvManager._initialized = true;
```

## 技術的詳細

### ファイル構成
- `workspace.kenv`: KENV v3.1.3形式のJSON設定ファイル
- `workspace.kindex`: 最適化されたインデックス（JSON）
- `workspace.kentry`: エントリーデータ（CSV、45カラム固定）

### 競合回避
- UploadHistoryManager: `kaspa-uploads.kenv`を引き続き使用
- FileState.kenvManager: `workspace.*`プレフィックスで新規ファイル使用
- 両システムが独立して動作可能

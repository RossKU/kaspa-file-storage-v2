# v5.11.40 変更内容 - KENV Phase 1-B アップロード時自動追加

## 実装日時
2025-07-30

## 概要
Phase 1-Bとして、アップロード完了時にKENVエントリーを自動的に追加する機能を実装。

## 主な変更点

### 1. アップロード完了時のKENVエントリー自動追加
FileState.fileOperationHandlers.processAndUpload内（12999-13042行目）：
```javascript
// v5.11.40: Phase 1-B - Add to KENV manager
if (FileState.kenvManager._initialized) {
    log('[KENV] アップロード完了エントリーを追加', 'info');
    const kenvEntry = FileState.kenvManager.addMinimalEntry(
        uploadData.name,
        'kaspa-file',
        'upload'
    );
    
    // 既知の情報を設定
    kenvEntry.fileSize = uploadData.size;
    kenvEntry.uploadDate = uploadData.uploadDate;
    // ... その他のプロパティ設定
    
    // インデックスを更新
    const lineNumber = FileState.kenvManager.entries.indexOf(kenvEntry);
    FileState.kenvManager.updateIndex(kenvEntry, lineNumber);
    
    // ファイルを保存（非同期で実行）
    FileState.kenvManager.saveAll().then(() => {
        log('[KENV] エントリーを保存しました', 'success');
        
        // File Tabが開いている場合は更新
        const activeTab = document.querySelector('.tab-content.active');
        if (activeTab && activeTab.id === 'file-tab') {
            window.updateFileListFromKENV();
        }
    });
}
```

### 2. メタTx作成後のKENVエントリー更新
createMetaTransaction関数内（13526-13556行目）：
```javascript
// v5.11.40: Phase 1-B - Update KENV entry with meta-tx info
if (FileState.kenvManager._initialized && window.currentFileCID) {
    log('[KENV] メタTx情報でエントリーを更新', 'info');
    const kenvEntries = FileState.kenvManager.entries;
    const kenvEntry = kenvEntries.find(e => e.cid === window.currentFileCID);
    
    if (kenvEntry) {
        kenvEntry.metaTxId = metaTxId;
        kenvEntry.metaTxBlockId = metaBlockId;
        kenvEntry.status = 'verified';
        
        // インデックスを更新
        const lineNumber = kenvEntries.indexOf(kenvEntry);
        FileState.kenvManager.updateIndex(kenvEntry, lineNumber);
        
        // ファイルを保存（非同期で実行）
        FileState.kenvManager.saveAll().then(() => {
            log('[KENV] メタTx情報を保存しました', 'success');
            
            // File Tabが開いている場合は更新
            const activeTab = document.querySelector('.tab-content.active');
            if (activeTab && activeTab.id === 'file-tab') {
                window.updateFileListFromKENV();
            }
        });
    }
}
```

### 3. File Tabの自動更新
- アップロード完了時にFile Tabが開いている場合、自動的に表示を更新
- メタTx情報追加後もFile Tabを自動更新

## 技術的詳細

### エントリー作成時の情報
- 基本情報: id, type, name, source, status
- ファイル情報: fileSize, mimeType, sha256, encrypted
- アップロード情報: uploadDate, uploadedBy, uploadCost
- 技術情報: cid, totalChunks, chunkSize, payloadSplit
- パスワード: password（暗号化されている場合）

### ステータス遷移
1. 初期状態: `pending`
2. メタTx作成後: `verified`

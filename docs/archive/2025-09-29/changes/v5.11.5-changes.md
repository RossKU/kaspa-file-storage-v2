# v5.11.5 Changes - Manual Archive Discovery Mode with Reset

## Changes
1. **Disabled auto-start of archive node discovery**
   - Removed automatic `startDiscovery()` call from `initialize()`
   - Archive discovery now requires manual start from debug tab

2. **Updated initial display**
   - Changed from "探索: - | 発見: -/- | 速度: -"
   - To "探索: 未開始 (デバッグタブから開始してください)"

3. **Added log message on manual start**
   - Shows "Archive node discovery started manually" when started

4. **Added reset button and functionality**
   - New "リセット" button in debug tab
   - `reset()` method clears all discovery data:
     - Stops current discovery
     - Resets statistics
     - Clears events log
     - Resets UI to initial state
     - Clears discovered archive nodes list
   - Useful for changing search conditions and re-running discovery

5. **Performance improvement**
   - Reduces CPU and memory usage by not running discovery automatically
   - User can choose when to start archive node discovery

6. **Archive node event log window expanded**
   - Changed max-height from 40px to 80px
   - Now displays approximately 6 lines (previously 3 lines)

7. **BlockDAG command usage clarification**
   - Changed "Checking: XM blocks" to "Checking BlockDAG: XM blocks"
   - Added debug logs: "Called getBlockDagInfo() to retrieve block count"
   - Added validation log: "Validating with getBlockDagInfo() - checking total block count"

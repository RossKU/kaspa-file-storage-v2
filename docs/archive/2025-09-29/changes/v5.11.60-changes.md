# v5.11.60 変更内容 - KENV処理を履歴処理から分離

## 実装日時
2025-07-31

## 概要
KENV（ファイル管理システム）の処理を履歴処理から完全に分離しました。これにより、履歴機能を無効化してもKENVは正常に動作します。

## 変更内容

### パターンC（完全分離）の実装
3箇所でKENV処理を履歴処理の外に移動：

1. **データ本体アップロード後**
   - ファイルアップロード完了時のKENVエントリー追加を独立処理に
   - 基本情報（ファイル名、サイズ、CID等）を記録

2. **MetaTx作成後**
   - メタトランザクション情報（metaTxId、metaTxBlockId）の更新を独立処理に
   - ステータスを'verified'に更新

3. **実際のコスト計算後**
   - 実際のアップロードコストの更新処理を新規追加
   - KENVエントリーのuploadCostを正確な値に更新

## 影響
- 履歴機能とファイル管理機能が完全に独立
- 履歴機能を無効化してもKENVは正常動作
- 3回の書き込みタイミングを明確に管理
- 将来的な履歴機能の削除が容易に

## テスト方法
1. ファイルをアップロード
2. ファイルタブでエントリーが作成されることを確認
3. メタTx作成後、メタ情報が更新されることを確認
4. 実際のコストが正しく表示されることを確認

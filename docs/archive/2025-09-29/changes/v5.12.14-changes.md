# v5.12.14: ディレクトリビルダーKENV統合

## 問題
- ディレクトリビルダーでMetaTxIDを生成してアップロード成功するが、KENVにファイルが登録されない
- Fileタブにディレクトリ情報が表示されない
- 通常のファイルアップロードではKENV登録されるが、ディレクトリではされない

## 原因
- DirectoryBuilderStateのuploadToBlockchain関数でKENVエントリー作成処理が欠落
- 通常のファイルアップロード（processAndUpload）ではKENV処理があるが、ディレクトリアップロードにはない

## 修正内容
1. **KENV登録処理追加（6090-6132行目）**
   - FileState.kenvManager.addMinimalEntryでエントリー作成
   - typeは'kaspa-directory'を使用
   - FileState.currentKenvEntryIdにセッションIDを保存

2. **ディレクトリ固有情報の追加**
   - fileCount: ファイル数
   - directoryCount: ディレクトリ数  
   - totalSize: 合計サイズ
   - metaTxId/metaTxBlockId: ブロックチェーン情報
   - network: ネットワーク設定

3. **Fileタブ連携**
   - KENV登録後にupdateFileTab()を呼び出し
   - FileタブでディレクトリがKENVから表示可能に

## 効果
- ディレクトリアップロード後、FileタブでKENVエントリーが表示される
- ディレクトリメタTxIDが正しくKENVに保存される
- 通常ファイルと同じようにディレクトリも履歴管理される

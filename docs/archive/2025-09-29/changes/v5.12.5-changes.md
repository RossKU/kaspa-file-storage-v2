# v5.12.5: スコープエラー修正＆キャッシュ対策

## 概要
ログファイル分析で判明した問題を修正し、ブラウザキャッシュ対策のためバージョンを更新。

## 発見された問題

### 1. スコープエラー
```
[13:22:09.531] [ERROR] 未処理のPromiseエラー: ReferenceError: updateUploadButtonState is not defined
```
- `updateUploadButtonState`は8052行目（module script内）で定義
- `handleFileSelect`から呼ばれるが、スコープが異なるため参照できない

### 2. 10秒タイマーが動作しない問題
- コード自体は正しく実装されている（v5.12.4）
- ブラウザが古いバージョンをキャッシュしている可能性

## 実装内容

### スコープ問題の修正（8079-8080行目）
```javascript
// v5.12.5: Export to window for cross-scope access
window.updateUploadButtonState = updateUploadButtonState;
```

### バージョン番号更新
- v5.12.4 → v5.12.5（キャッシュ無効化のため）

## 効果
- ✅ ファイル選択時のエラーが解消
- ✅ アップロードボタンの状態が正しく更新される
- ✅ ブラウザキャッシュが更新される
- ✅ 10秒タイマーが正常に動作する

## テスト確認事項
1. ファイル選択時にエラーが出ないこと
2. アップロード完了後10秒で表示が消えること
3. Ctrl+Shift+R（強制リロード）後に正常動作すること

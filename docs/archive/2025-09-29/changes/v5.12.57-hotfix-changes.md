# v5.12.57-hotfix: Info表示エラー修正

## 問題
- FileState.fileListがundefinedでエラー発生
- "Cannot read properties of undefined (reading 'find')"エラー

## 原因
- FileState.fileListが初期化される前にアクセス
- KENVからのデータ取得が不完全

## 修正内容

### エラーハンドリング追加
```javascript
// Get file from KENV entries or fileList
let file = null;

// First try to get from KENV entries
const kenvEntries = FileState.kenvManager.getEntries();
if (kenvEntries && kenvEntries.length > 0) {
    file = kenvEntries.find(f => f.id === selectedIds[0]);
}

// Fallback to fileList if available
if (!file && FileState.fileList) {
    file = FileState.fileList.find(f => f.id === selectedIds[0]);
}

if (!file) {
    alert('ファイル情報が見つかりません');
    return;
}
```

## 効果
- KENVエントリーから優先的にデータ取得
- FileState.fileListは代替手段として使用
- undefinedエラーを防止
- ユーザーへの適切なフィードバック

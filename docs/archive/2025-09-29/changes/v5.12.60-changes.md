# v5.12.60: fileSize統一

## 背景
- v5.12.59で`file.size || file.fileSize`と修正したが、混乱を招く
- `file.size`プロパティは実際には存在しない（KENVデータでは）

## 調査結果
### プロパティの使用状況：
1. **保存時（13378行目）**: `kenvEntry.fileSize = currentFile.size`
2. **CSV読み込み（4702行目）**: `entry.fileSize`として読み込み
3. **テーブル表示（17915行目）**: `entry.fileSize`を参照
4. **Infoボタン（18516行目）**: ~~`file.size`~~ → `file.fileSize`

### データ構造：
- KENVエントリーは常に`fileSize`プロパティを持つ
- `size`プロパティは存在しない（v5.12.58の互換性処理を削除）

## 修正内容

### 1. Info表示の単純化（18516行目）
```javascript
// 修正前（v5.12.59）
formatSize(file.size || file.fileSize)

// 修正後
formatSize(file.fileSize)
```

### 2. CSV読み込みの単純化（4702行目）
```javascript
// 修正前
if (values[15]) {
    entry.fileSize = parseInt(values[15]) || null;
    entry.size = entry.fileSize;  // 互換性処理
}

// 修正後
if (values[15]) entry.fileSize = parseInt(values[15]) || null;
```

### 3. ディレクトリ処理の更新（14561行目）
```javascript
// 修正前
fileItem.size = entry.size || 0;

// 修正後
fileItem.size = entry.fileSize || entry.size || 0;  // fileSizeを優先
```

## 効果
- プロパティ名の一貫性向上
- 混乱の原因となる不要な互換性コードを削除
- コードの可読性向上

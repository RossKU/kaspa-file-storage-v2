# v5.12.76: Kaspaシステム再起動機能を設定タブに移動

## 変更内容

### 1. 機能の移動と名称変更
- **旧**: デバッグタブ「システム初期化」
- **新**: 設定タブ「Kaspaシステム再起動」
- 設定タブの最下部に配置

### 2. UIの改善
- 名称を「Kaspaシステム再起動」に変更
- 「WASM SDKとKaspa core.jsを再起動してクリーンな状態にします」という説明を追加
- 「接続エラーや動作不良時にお試しください」というヘルプテキスト追加
- 接続テストボタンを削除（シンプル化）

### 3. 表示メッセージの改善
- **再起動完了メッセージ**: 「✅ 再起動完了」と表示
- 5秒後に自動的に非表示
- Wallet接続関連の表示を削除（設定タブに別項目として存在するため）

### 4. エラーメッセージの更新
- すべてのエラーメッセージで「システムを初期化」→「Kaspaシステムを再起動」に変更
- エラー時の案内も「設定タブから」と明記

- デバッグタブが完全に開発者向け機能のみに
- 一般ユーザー向けのシステム管理機能が設定タブに集約
- より直感的でわかりやすいUI

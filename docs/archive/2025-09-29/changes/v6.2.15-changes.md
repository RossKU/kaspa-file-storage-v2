# v6.2.15 Changes - Fix UTXO Status Update After Consolidation

## Date: 2025-08-18

## Issue
After successful UTXO consolidation, error occurred:
```
TypeError: this.checkUTXOStatus is not a function
```

## Root Cause
- v6.2.14 removed the `checkUTXOStatus()` function from DebugHandlers
- But `consolidateUTXOs()` was still calling `this.checkUTXOStatus()` after success
- Browser cache was serving old v6.2.14 code despite hotfix deployment

## Solution
Replace the removed function call with direct UTXO status update code:
- Directly fetch UTXO data after consolidation
- Update all display elements (balance, UTXO count, button state)
- Same logic as wallet connection UTXO update

## Code Changes
```javascript
// OLD (line 3009)
this.checkUTXOStatus();

// NEW
const { entries } = await NetworkState.rpcClient.getUtxosByAddresses([UserState.address.toString()]);
// Update displays directly...
```

## Additional Measures
- Version bump to v6.2.15 to force cache refresh
- Direct implementation ensures no dependency on removed functions

## Testing
- UTXO consolidation should complete without errors
- Balance and UTXO count should update after 5 seconds
- Consolidate button should show "Consolidation not needed" when UTXOs = 1

# v6.2.16 Changes - Use CSS Variables for UTXO Consolidation Button

## Date: 2025-08-18

## Overview
Replace hardcoded color values with CSS variables for better theme consistency and maintainability.

## Changes

### 1. HTML Button Styling
**Before:**
```html
style="background: #2A6F65; color: white;"
```

**After:**
```html
style="background: var(--accent-color); color: var(--button-text-on-accent);"
```

### 2. JavaScript Dynamic Styling
**Before:**
```javascript
consolidateBtn.style.background = '#2A6F65';
```

**After:**
```javascript
consolidateBtn.style.background = 'var(--accent-color)';
```

### 3. Configuration
**Before:**
```javascript
accentColor: "#2A6F65"
```

**After:**
```javascript
accentColor: "var(--accent-color)"
```

## Benefits
- Consistent color scheme across light/dark themes
- No hardcoded colors scattered in the code
- Easy to change accent colors globally via CSS variables
- Better maintainability

## CSS Variable Values
- `--accent-color`: #70C7BA (light) / #389486 (dark)
- `--warning-color`: #ffc107 (both themes)
- `--button-text-on-accent`: #16213e (both themes)

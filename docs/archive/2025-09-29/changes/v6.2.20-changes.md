# v6.2.20 Changes - Fix Directory Info Display
## Date: 2025-08-19

## Problem
The File tab's Info button showed incorrect information for directories:
- Type displayed as "📄 File" instead of "📁 Directory"
- No directory-specific information shown

## Root Cause
`FileTabHandlers.showSelectedFileDetails()` was checking for `type === 'directory'` but actual value is `'kaspa-directory'`

## Changes
### 1. Fixed Type Check (Line 18858)
- Changed from `'directory'` to `'kaspa-directory'`
- Now correctly displays "📁 Directory" for directories

### 2. Added Directory Information Display
- Shows file count, subdirectory count, and total size
- Lists directory contents with file sizes
- Scrollable list for large directories

### 3. English Translation
- Changed Japanese labels to English for consistency
- サイズ → Size
- タイプ → Type
- アップロード日 → Upload Date
- 登録日 → Created Date
- ネットワーク → Network
- チャンク数 → Chunks
- 暗号化 → Encrypted

## Testing
1. Upload a directory using Directory Builder
2. Select the directory in File tab
3. Click Info button
4. Verify:
   - Type shows "📁 Directory"
   - Directory contents are listed
   - File/folder counts are correct

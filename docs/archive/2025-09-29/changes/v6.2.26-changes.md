# v6.2.26 Changes - Save All Basic Metadata Information to KENV

## Date: 2025-08-20

## Changes
Extended the `verifyAndCompleteEntry` function to save ALL basic metadata information (excluding large arrays like chunks) to KENV entries.

## Added Information Storage

### Basic Metadata
- `entry.version` - Metadata version (e.g., "3.3")
- `entry.cid` - Content Identifier

### File Information (kaspa-file)
- `entry.fileSize` - File size (used for display)
- `entry.size` - File size (kept for compatibility)
- `entry.mimeType` - MIME type (e.g., "image/jpeg")
- `entry.sha256` - SHA256 hash
- `entry.encrypted` - Encryption flag

### Compression Information
- `entry.compressionAlgorithm` - Compression algorithm
- `entry.compressionEnabled` - Compression enabled flag
- `entry.originalSize` - Original file size
- `entry.compressedSize` - Compressed file size

### Directory Information (kaspa-directory)
- `entry.totalSize` - Total directory size
- `entry.fileCount` - Number of files
- `entry.directoryCount` - Number of subdirectories

### Encryption Information
- `entry.encryptionAlgorithm` - Encryption algorithm (e.g., "AES-256-GCM")
- `entry.pbkdf2Salt` - PBKDF2 salt
- `entry.pbkdf2Iterations` - PBKDF2 iterations

### Recovery Information
- `entry.totalChunks` - Total number of chunks
- `entry.chunkSize` - Size of each chunk
- `entry.checksum` - File checksum
- `entry.uploadCost` - Upload cost in KAS

## Impact
- All basic metadata is now preserved in KENV entries
- Better information availability for file management

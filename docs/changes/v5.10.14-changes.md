# v5.10.14 変更内容

## 🔨 概要
グローバル変数`window.tempDirectoryMetadata`を削除し、DirectoryBuilderState内に移動しました。

## 🔧 変更内容

### アーキテクチャ改善
- **グローバル変数の削除**: `window.tempDirectoryMetadata`を削除
- **DirectoryBuilderStateへの統合**: 
  - `generatedMetadata`プロパティを追加
  - 生成されたメタデータを内部で管理

### 修正箇所
```javascript
// 以前
window.tempDirectoryMetadata = {
    metadata: metadata,
    password: password
};

// 修正後
this.generatedMetadata = {
    metadata: metadata,
    password: password
};
```

### 影響範囲
- `generateOnly()`: DirectoryBuilderState内に保存
- `generateAndUpload()`: DirectoryBuilderState内に保存
- `exportAsKaspa()`: DirectoryBuilderStateから参照
- `reset()`: generatedMetadataもリセット

# v5.10.16 変更内容

## 📁 概要
サブディレクトリ作成機能を復活させました。選択したフォルダに空のサブディレクトリを作成できます。

## 🔧 変更内容

### UI追加
- **新規フォルダ作成ボタン**: 「選択中の場所に新規フォルダを作成」
- TxID入力欄の下に配置
- 選択中のフォルダがわかりやすく表示

### 機能実装
- `createEmptyFolder()`: 空のディレクトリを作成
  - フォルダ名の入力プロンプト
  - 重複チェック
  - 作成後に自動選択

### 操作フロー
1. ツリービューでフォルダを選択（またはルート）
2. 「新規フォルダを作成」ボタンをクリック
3. フォルダ名を入力
4. 新しいフォルダが作成され、自動的に選択される
5. さらにサブフォルダやファイルを追加可能

## 🎯 使用例
```
📁 My Directory
├─ 📁 documents [選択中]
│  └─ [ここに追加...]
└─ 📁 images

↓ 「新規フォルダを作成」→ "2024" と入力

📁 My Directory
├─ 📁 documents
│  └─ 📁 2024 [自動選択]
│     └─ [ここに追加...]
└─ 📁 images
```

## 📝 技術的詳細
- type: 'directory' で metaTxId: null のエントリーとして管理
- フルパスで重複チェック
- 階層構造は自動的に構築される

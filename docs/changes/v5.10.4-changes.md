# v5.10.4 変更内容 - ディレクトリCID対応

## 概要
ディレクトリメタデータをフォーマットv3.3.0仕様に準拠させ、CIDフィールドを追加しました。

## 主な変更点

### 1. ディレクトリCID生成関数の追加
- **新規関数**: `generateDirectoryCID(uploadedFiles)`（7282-7320行目）
- **v3.3.0仕様準拠のCID計算ロジック**:
  1. 全エントリーから(metaTxId, ディレクトリパス)のペアを抽出
  2. pathからファイル名を除去（ディレクトリパスのみ使用）
  3. "metaTxId:ディレクトリパス"でソート（辞書順、大文字小文字を区別）
  4. 重複を除去
  5. 改行文字（\n）で結合
  6. UTF-8エンコード
  7. SHA-256ハッシュ計算
  8. Base64 URL-safeエンコード

### 2. createDirectoryMetadata関数の改善
- **CIDフィールドの追加**（7366行目）
- **バージョン番号を"3.3"に更新**（7343行目）
- ディレクトリの一意識別とコンテンツ検証が可能に

## 技術的詳細

### CID計算の実装
```javascript
// metaTxId:ディレクトリパス形式でペアを作成
const pairs = uploadedFiles.map(file => {
    const pathParts = file.path.split('/');
    pathParts.pop(); // ファイル名を除去
    const dirPath = pathParts.join('/') || '.';
    return `${file.metaTxId}:${dirPath}`;
});
```

### 仕様準拠のメリット
- v3.3.0仕様を期待するシステムとの互換性確保
- ディレクトリ内容の変更検知が可能
- 同じファイル構成なら同じCIDが生成される（決定論的）

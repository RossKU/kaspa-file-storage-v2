# v5.11.103 変更内容 - SystemHandlers is not definedエラー修正

## 実施日時
2025-08-02

## 変更内容
HTMLのonclick属性を削除し、module script内でaddEventListenerを使用してイベントを設定

## 背景
- ウォレット接続時に「Uncaught ReferenceError: SystemHandlers is not defined」エラーが発生
- SystemHandlersはmodule script内で定義されているが、windowに公開されていない
- HTML内のonclick属性（1423, 1972, 1974行）からSystemHandlers.xxxを呼び出している
- windowへの公開は後方互換用なので使用禁止

## 実装内容

### 1. HTMLのonclick属性を削除
- 1423行: `onclick="SystemHandlers.connectWallet()"` → 削除
- 1972行: `onclick="SystemHandlers.initializeSystem()"` → 削除
- 1974行: `onclick="SystemHandlers.testConnection()"` → 削除

### 2. DOMContentLoadedイベント内でaddEventListener追加（15202行付近）
```javascript
// v5.11.103: Add event listeners for buttons (replacing onclick attributes)
const walletConnectBtn = document.getElementById('walletConnectBtn');
if (walletConnectBtn) {
    walletConnectBtn.addEventListener('click', () => SystemHandlers.connectWallet());
}

const initBtn = document.getElementById('initBtn');
if (initBtn) {
    initBtn.addEventListener('click', () => SystemHandlers.initializeSystem());
}

const testBtn = document.getElementById('testBtn');
if (testBtn) {
    testBtn.addEventListener('click', () => SystemHandlers.testConnection());
}
```

## 結果
- カプセル化を維持しながらボタンクリックイベントが正常に動作
- module script内でイベントハンドリングが完結
- windowへの不要な公開を回避

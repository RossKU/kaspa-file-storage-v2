# v5.11.126: アップロードUIのシンプル化（Phase 1）

## 変更内容

### 1. 新しいシンプルなUIの追加
- チャンクリストを非表示に（backward compatibilityのためHTML要素は保持）
- ステータスメッセージ、経過時間、残り時間を表示する新UI追加
- 技術的な詳細を隠して、ユーザーフレンドリーな表示に変更

### 2. 新しいUI要素

**CSS追加**（629-682行）：
- `.upload-status-container`: メインコンテナ
- `.upload-status-message`: アイコンとステータスメッセージ
- `.upload-time-info`: 経過時間と残り時間
- `@keyframes pulse`: パルスアニメーション
- `@keyframes spin`: 回転アニメーション

**HTML追加**（1671-1686行）：
```html
<div class="upload-status-container">
    <div class="upload-status-message">
        <span class="upload-status-icon" id="uploadStatusIcon">📦</span>
        <span id="uploadStatusText">準備中...</span>
    </div>
    <div class="upload-time-info">
        <span id="uploadElapsedTime">経過時間: 0秒</span>
        <span id="uploadRemainingTime">残り時間: 計算中...</span>
    </div>
</div>
```

### 3. アップロードフェーズと表示

1. **準備フェーズ** 🔐
   - 「ファイルを準備しています...」
   - 「ファイルを暗号化しています...」

2. **最適化フェーズ** 📦
   - 「データを最適化しています...」

3. **送信フェーズ** ⬆️
   - 「ブロックチェーンに送信しています... (x/y)」

4. **確認フェーズ** ⏳
   - 「トランザクションを確認しています...」

5. **完了フェーズ** ✅
   - 「完了！ファイルIDをコピーしてください」

### 4. 時間推定機能
- 各チャンクのアップロード時間を記録
- 移動平均（80%既存 + 20%新規）で残り時間を推定
- 最初のチャンクが完了するまでは「計算中...」と表示

### 5. 実装詳細

**uploadStatusUIオブジェクト**（12081-12151行）：
- `updateStatus()`: ステータス更新
- `updateRemainingTime()`: 残り時間計算
- `recordChunkTime()`: チャンク時間記録
- `reset()`: 初期化

**統合箇所**：
- 12228行: 初期化時
- 12316行: 暗号化時
- 12426行: 最適化時
- 12526行: 送信開始時
- 12779行: チャンク完了時
- 13371行: メタTx作成時
- 13404行: 完了時
- 13477行: エラー時の非表示

# v5.11.130: カスタムRPCエンドポイント機能の有効化

## 実装内容

既に存在していたカスタムRPCエンドポイントのUI要素を機能させました。

### 変更内容：

1. **HTMLのonchange属性を削除**
   - `onchange="onNodeTypeChange()"`を削除（未定義関数だったため）

2. **イベントハンドラーの実装**
   - ノードタイプ選択時の表示/非表示切り替え
   - カスタムエンドポイント入力値をconfig.customEndpointに保存
   - ノードタイプ変更時の自動再接続

### 使い方：

1. 設定タブで「ノードタイプ」を「カスタム」に選択
2. カスタムRPCエンドポイント入力欄が表示される
3. WebSocketエンドポイントを入力（例: `wss://your-node.example.com:17210`）
4. システムを初期化すると、入力したエンドポイントに接続

### 特徴：

- ネットワーク切り替えと同じパターンで実装
- 既存のcreateRpcClient関数がカスタムエンドポイントを適切に処理
- ノードタイプ変更時に自動的に再接続
- 入力値は即座にconfigに反映

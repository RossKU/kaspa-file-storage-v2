# v5.11.135: アップロードボタンの状態遷移修正

## 修正内容

アップロードボタンの状態遷移が正しく動作するよう全面的に修正しました。

### 問題点：
1. 初期状態でdisabledなのに緑色表示
2. アップロード完了後も有効のまま
3. 条件判定が不完全（ウォレットのみチェック）

### 修正実装：

#### 1. 初期状態の修正（1626行目）
```html
<!-- Before -->
background: var(--accent-color);  // 緑色

<!-- After -->
background: var(--text-secondary); // グレー
cursor: not-allowed;
```

#### 2. updateUploadButtonState関数の改良（8297-8323行目）
- 3条件すべてをチェック：
  - ウォレット接続（UserState.address）
  - ファイル選択（FileState.currentFile）
  - パスワード入力（8文字以上）
- forceStateパラメータ追加（アップロード中の制御用）

#### 3. アップロード完了後の処理（13061-13074行目）
- FileState.currentFileをnullにクリア
- updateUploadButtonState()で再評価（disabled状態に）

#### 4. イベントハンドラー追加
- パスワード入力時にボタン状態を更新（15514行目）
- ファイル選択時にボタン状態を更新（16581行目）

## 状態遷移フロー

1. **初期状態**: グレー（disabled）
2. **3条件揃う**: 緑（enabled）
3. **アップロード中**: グレー（disabled）
4. **完了後**: グレー（disabled）← ファイル・パスワードがクリアされたため

## 影響範囲
- UX向上：ボタンの視覚的状態が実際の動作と一致
- セキュリティ：アップロード完了後の適切なクリア処理

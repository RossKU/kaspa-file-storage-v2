# v5.11.53 変更内容 - 色の最終最適化（19色体系へ）

## 実装日時
2025-07-31

## 概要
CSS変数を23種類から19種類に削減し、最終的な色体系を確立しました（総削減率62%）。

## 削減内容

### 1. サイドバー専用色の削除（2色）
- **`--sidebar-text-secondary`** → 削除
  - 使用箇所: `appSubtitle`（1箇所）
  - 対応: `opacity: 0.8`を直接適用
  
- **`--sidebar-border-light`** → 削除
  - 使用箇所: `sidebar-header`のボーダー（1箇所）
  - 対応: `--sidebar-border`に統合

### 2. ボーダー色の統合（1色）
- **`--border-darker`** → 削除
  - 使用箇所: `fileListHtml`（1箇所）
  - 対応: `--border-dark`で代替

### 3. ステータス色の統合（1色）
- **`--status-connected`** → 削除
  - 使用箇所: 接続状態表示、ボタン背景、テキスト色など（7箇所）
  - 対応: `--success-color`に統合（接続成功の意味で統一）

## 最終的な色構成（19色）

### 基本色（5種類）
1. `--bg-primary` - メイン背景
2. `--bg-secondary` - セカンダリ背景
3. `--text-primary` - メインテキスト
4. `--text-secondary` - サブテキスト
5. `--border-color` - 標準ボーダー

### アクセント色（3種類）
6. `--accent-color` - メインアクセント
7. `--accent-hover` - ホバー状態
8. `--accent-light` - 薄いアクセント

### ステータス色（4種類）
9. `--success-color` - 成功/接続済み（統合）
10. `--error-color` - エラー/危険/切断
11. `--warning-color` - 警告/接続中
12. `--info-color` - 情報

### 特殊用途（7種類）
13. `--sidebar-text` - サイドバーテキスト
14. `--sidebar-border` - サイドバーボーダー
15. `--tooltip-bg` - ツールチップ背景
16. `--text-on-warning` - 警告色上のテキスト
17. `--button-text-on-accent` - アクセント色上のボタンテキスト
18. `--border-dark` - 濃いボーダー（darkerも統合）
19. `--code-bg` - コード背景

### サイドバー専用（追加2種類 = 計21種類）※shadow除く
※shadowsは`--shadow-sm`と`--shadow-md`の2種類

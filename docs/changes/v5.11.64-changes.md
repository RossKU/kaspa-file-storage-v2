# v5.11.64 変更内容 - .kaspaファイル生成機能追加

## 実装日時
2025-07-31

## 概要
Fileタブの共有メニューに.kaspaファイル生成機能を追加しました。これにより、KENVエントリーから直接.kaspaファイルを生成できるようになりました。

## 変更内容

### 1. generateKaspaFromKENV()関数の追加
KENVエントリーから.kaspaファイルを生成する関数を実装：
- メタトランザクション情報の確認
- .kaspaファイルのメタデータ構造作成
- パスワード付き/なしの両方に対応

### 2. shareAction()の更新
- 'kaspa-password'アクション: パスワード付き.kaspaファイル生成
- 'kaspa-no-password'アクション: パスワードなし.kaspaファイル生成

### 3. .kaspaファイル構造
生成される.kaspaファイルには以下の情報が含まれます：
- メタトランザクションID/BlockID
- ファイル情報（名前、サイズ、SHA256、CID）
- アップロード情報（日時、アップローダー、コスト）
- 認証情報（パスワード付きの場合）

## 影響
- ダウンロードエラーの原因調査が可能に
- .kaspaファイルの内容を確認できるように
- 履歴システムに依存しない実装

## テスト方法
1. Fileタブでファイルを選択
2. Shareボタンをクリック
3. 「🔐 .kaspa (パスワード付き)」または「🔓 .kaspa (パスワードなし)」をクリック
4. .kaspaファイルがダウンロードされることを確認
5. ファイルの中身を確認してメタデータが正しいことを検証

# v5.11.65 変更内容 - .kaspaファイルフォーマット修正

## 実装日時
2025-07-31

## 概要
.kaspaファイル生成時のエラーを修正し、フォーマットを元の実装（v3.3）に完全に一致させました。

## 変更内容

### 1. config参照エラーの修正
- `config.network`が未定義だったエラーを修正
- 固定値`"testnet-10"`を使用

### 2. フォーマットをv3.3に統一
元の実装に合わせて以下の構造に変更：
- version: "3.3"（"3.4.2"から変更）
- トップレベルに`created`, `network`, `encryption`を配置
- `chunks`と`chunkBlockIds`配列を追加（KENVには詳細がないため空配列）
- `recovery`セクションを追加
- `metadata`セクションに必要な情報を配置
- `chunkStructure`セクションを追加
- `auth`セクションを追加

### 3. 必要なフィールドの追加
- compression情報の追加
- payloadSplit、segmentBoundariesの追加
- 各種数値フィールドのパース処理

## 影響
- .kaspaファイル生成エラーが解消
- 生成されたファイルがダウンロード処理と互換性を持つ
- ファイル内容の確認が可能に

## テスト方法
1. Fileタブでファイルを選択
2. Share → 「🔐 .kaspa (パスワード付き)」をクリック
3. エラーなく.kaspaファイルが生成されることを確認
4. 生成されたファイルの内容がv3.3フォーマットであることを確認

# v5.11.83-hotfix 変更内容 - .kprogressファイル削除処理の復活

## 問題
v5.11.83で履歴追加ブロックを削除した際、誤って.kprogressファイル削除処理も一緒に削除してしまった。
これにより、アップロード完了後も.kprogressファイルが残ってしまう問題が発生。

## 原因
v5.11.81では以下の構造だった：
```javascript
if (WorkspaceState.historyManager) {
    // 履歴追加処理（12497-12549行）
    // ...
    
    // .kprogressファイル削除処理（12575-12584行）
    if (FileState.progressManager && WorkspaceState.handle) {
        // ...
    }
}
```

v5.11.83では履歴マネージャーのifブロック全体を削除してしまったため、.kprogressファイル削除処理も消えてしまった。

## 修正内容
.kprogressファイル削除処理（12496-12505行）を復活：
- 履歴機能とは無関係な必須処理として独立して配置
- アップロード完了後に確実に実行される位置に配置

## 影響
- .kprogressファイルが正常に削除されるようになる
- 履歴機能の削除には影響なし

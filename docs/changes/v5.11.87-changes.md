# v5.11.87 変更内容 - モバイルサイドバー左側空間修正

## 実施日時
2025-08-02

## 変更内容
コンパクトモードからモバイルサイズに変更した際に、メインコンテンツの左側に空間が残る問題を修正

## 問題の原因
1. デスクトップでコンパクトモード時、body.sidebar-collapsedクラスが適用
2. .sidebar-collapsed .main-content { margin-left: 60px; } が設定される
3. モバイルサイズに変更してもbody.sidebar-collapsedクラスが残る
4. CSS詳細度の問題で、モバイルの margin-left: 0 が効かない

## 修正内容
モバイル用メディアクエリ内で .sidebar-collapsed .main-content のmargin-leftを明示的に0に設定

## 技術的詳細
- @media (max-width: 768px) 内で詳細度の高いセレクタを使用
- !importantで確実に上書き

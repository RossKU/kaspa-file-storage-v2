# v5.11.88 変更内容 - モバイルUX改善

## 実施日時
2025-08-02

## 変更内容
モバイルでのサイドバー操作性を改善

## 実装内容
### 1. サイドバー展開時のハンバーガーメニュー非表示
- サイドバーが開いているときはハンバーガーメニューを非表示に
- CSSで.sidebar.open時の.mobile-menu-btnをdisplay: noneに設定

### 2. サイドバー外クリックで閉じる機能
- オーバーレイ要素を追加（#sidebar-overlay）
- サイドバー展開時にオーバーレイを表示
- オーバーレイクリックでサイドバーを閉じる
- 半透明の黒背景（rgba(0,0,0,0.5)）で実装

## 技術的詳細
- オーバーレイのz-index: 999（サイドバーより下層）
- サイドバーのz-index: 1000（そのまま）
- ハンバーガーメニューのz-index: 1001（そのまま）
- toggleSidebar関数にオーバーレイの表示/非表示処理を追加
- オーバーレイにクリックイベントリスナーを設定

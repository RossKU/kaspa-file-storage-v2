# v5.11.9 Changes - RPC Connection Information Display

## Changes
1. **Added RPC node information display**
   - Shows network type (Testnet-10/Mainnet)
   - Shows server version (e.g., kaspad/0.12.11)
   - Shows sync status (Synced/Syncing)
   - Shows node type (Archive/Custom/Standard)
   - Shows endpoint URL when available

2. **New function updateRpcNodeInfo()**
   - Updates UI with connection information
   - Handles disconnected state gracefully
   - Formats information for clear display

3. **Updated connection handlers**
   - initializeSystem: Updates UI on connection
   - initializeRpcClient: Updates UI on reconnection
   - ConnectionManager: Updates UI on recovery
   - Error handlers: Resets UI on failure

4. **Display format examples**
   - Connected: "Node: Testnet-10 • kaspad/0.12.11 • Synced • Archive Node (wss://archive-tn10.kaspa.org:17210)"
   - Connected: "Node: Mainnet • kaspad/0.12.11 • Synced • Standard (Auto)"
   - Disconnected: "RPC Client: 🔴 Not Connected / Node: -"

## Purpose
- Provides transparency about RPC connection status and node details
- Helps users understand which node they're connected to
- Shows important node characteristics (archive/pruned status)
- Improves debugging and troubleshooting

# v5.11.90 変更内容 - シャドウ（オーバーレイ）削除

## 実施日時
2025-08-02

## 変更内容
モバイルサイドバーのシャドウ（オーバーレイ）機能を削除し、よりシンプルな実装に変更

## 削除理由
1. メニュー選択時にオーバーレイが残る問題
2. オーバーレイクリック時の処理が複雑
3. アニメーションタイミングの管理が困難

## 実装内容
### 削除
- HTML: sidebar-overlay要素
- CSS: .sidebar-overlayスタイル
- JavaScript: オーバーレイ関連処理

### 新規実装
- documentクリックイベントでサイドバー外クリック検知
- サイドバー内クリックは伝播停止（stopPropagation）
- よりシンプルで一般的な実装方式

## 技術的詳細
- オーバーレイなしでもUXは維持
- パフォーマンス向上（DOM要素削減）
- 多くのモバイルサイトで採用されている標準的な方法

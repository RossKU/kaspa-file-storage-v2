# v5.12.15: サムネイル表示修正

## 問題
- アップロード完了後、2回目のファイル選択時にサムネイル/ファイル情報が表示されない
- ファイル選択UI要素が見つからずエラーになる

## 真の原因
- v5.11.135で追加された処理（13028-13035行目）がHTML構造を破壊
- `label.innerHTML`でファイル選択UIの中身を全て上書き
- `thumbnailPreview`、`thumbnailImage`、`fileDetails`などの要素が削除される
- 2回目のファイル選択時、`showFileInfo`が必要な要素を見つけられない

## 修正内容（13027-13030行目）
```javascript
// 修正前
const label = document.querySelector('.file-input-label');
if (label) {
    label.innerHTML = `
        📁 ファイルを選択<br>
        <small>またはドラッグ&ドロップ</small>
    `;  // ❌ HTML構造を破壊
    label.classList.remove('file-selected', 'resume-mode');
}

// 修正後
if (typeof clearFileSelection === 'function') {
    clearFileSelection();  // ✅ HTML構造を保持
}
```

## 効果
- `clearFileSelection()`関数が適切にUIをリセット
- HTML構造（thumbnailPreview、defaultPrompt等）が保持される
- 2回目以降のファイル選択でもサムネイル/アイコンが正常表示
- ファイル情報の更新が正しく動作

## 技術詳細
`clearFileSelection()`関数の動作：
1. thumbnailPreviewを非表示
2. defaultPromptを表示
3. thumbnailImageをクリア
4. fileIconDivを非表示
5. FileStateをリセット
6. **HTML構造は変更しない（重要）**

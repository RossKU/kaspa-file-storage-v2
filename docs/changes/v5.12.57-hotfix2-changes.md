# v5.12.57-hotfix2: getEntriesエラー修正

## 問題
- `TypeError: FileState.kenvManager.getEntries is not a function`
- Infoボタンクリック時にエラー発生

## 原因
- `getEntries()`というメソッドは存在しない
- 正しくは`entries`プロパティに直接アクセスする必要があった

## 修正内容

### 誤ったコード
```javascript
// getEntries()メソッドを呼び出そうとしていた（存在しない）
const kenvEntries = FileState.kenvManager.getEntries();
```

### 正しいコード
```javascript
// entriesプロパティに直接アクセス
const kenvEntries = FileState.kenvManager.entries;
```

## KENVマネージャーの構造
```javascript
FileState.kenvManager = {
    entries: [],  // ← これが正しいプロパティ
    // getEntries()というメソッドは存在しない
}
```

## 効果
- エラーが解消
- Infoボタンが正常に動作
- ファイル情報が正しく表示される

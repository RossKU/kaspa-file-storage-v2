# v5.12.61: showFileInfo関数名衝突修正

## 問題
- ファイルアップロード機能が壊れた
- ファイルを選択できず、Fileタブで選択したファイルの情報が表示される

## 原因
`window.showFileInfo`が2箇所で重複定義されていた：

1. **17272行目**: アップロード時のファイル表示用
   - 引数: `(file, thumbnailUrl)`
   - 用途: ファイル選択時のサムネイル/情報表示

2. **18467行目**: Fileタブのinfo表示用
   - 引数: なし
   - 用途: Fileタブで選択したファイルの詳細表示
   - **これが前者を上書きしていた**

## 修正内容

### 関数名の変更
```javascript
// 修正前
window.showFileInfo = function() {  // Fileタブ用
    const selectedIds = Array.from(FileState.selectedFiles);
    ...
}

// 修正後
window.showFileTabInfo = function() {  // 名前を変更
    const selectedIds = Array.from(FileState.selectedFiles);
    ...
}
```

### HTMLボタンのonclick修正（1943行目）
```html
<!-- 修正前 -->
<button class="file-action-btn" onclick="showFileInfo()">

<!-- 修正後 -->
<button class="file-action-btn" onclick="showFileTabInfo()">
```

## 効果
- アップロード機能が正常に動作
- ファイル選択時にサムネイル/情報が正しく表示される
- Fileタブのinfo機能も正常に動作
- 関数名の衝突を回避

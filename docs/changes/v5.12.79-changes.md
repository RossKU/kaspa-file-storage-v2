# v5.12.79: UTXO数表示機能追加

## 新機能
- Wallet接続時に残高と一緒にUTXO数を表示
- Uploadタブとステータスタブの両方に表示
- 40個を超えると警告アイコン（⚠️）を表示

## 技術的詳細
- `getUtxosByAddresses()`でentriesを取得
- `entries.length`でUTXO数をカウント
- 形式: `(UTXOs: N)` 

## 表示箇所
1. Uploadタブ: 残高の隣に表示
2. ステータスタブ: 残高の隣に表示

## 警告機能
- UTXO数が40個を超えると⚠️アイコンを表示
- Storage mass問題の事前把握が可能

## 背景
- 多数のUTXOが蓄積するとトランザクションのmassが増加
- 特にペイロード付きトランザクションで問題になりやすい
- 事前にUTXO統合の必要性を判断できる

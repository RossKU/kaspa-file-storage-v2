# v5.7.12 変更内容

## 修正内容
currentPasswordプロパティの重複定義エラーを修正しました。

### 問題
```javascript
TypeError: Cannot redefine property: currentPassword
at Object.defineProperty (<anonymous>)
```

### 原因
同じプロパティ`currentPassword`が2回定義されていました：

1. **v5.5.3での定義**（2010-2016行目）- configurable: false（デフォルト）
2. **v5.5.20での定義**（2216-2223行目）- configurable: true + try-catch

最初の定義がconfigurable: falseのため、2回目の定義でエラーが発生していました。

### 解決方法
重複している最初の定義（v5.5.3）を削除し、try-catch付きの定義（v5.5.20）のみを残しました。

#### 削除したコード
```javascript
// v5.5.3: Define getter/setter for currentPassword
Object.defineProperty(window, 'currentPassword', {
    get() { return FileState.currentPassword; },
    set(value) { 
        FileState.currentPassword = value;
    }
});
```

#### 残したコード
```javascript
// v5.5.20: currentPasswordの後方互換性プロキシ
// v5.5.21: configurableオプションを追加して再定義エラーを回避
// v5.7.12: 重複定義を削除（v5.5.3の定義を削除し、このtry-catch付きの定義のみを残す）
try {
    Object.defineProperty(window, 'currentPassword', {
        get() { return FileState.currentPassword; },
        set(value) { 
            FileState.currentPassword = value;
        },
        configurable: true,  // 再定義を許可
        enumerable: true     // for...inで列挙可能
    });
} catch (e) {
    // 既に定義されている場合はスキップ
    console.warn('currentPassword proxy already defined:', e);
}
```

## 影響
- **エラーの解消**: TypeError: Cannot redefine propertyが発生しなくなります
- **動作の変更**: なし（機能的には同じ）
- **互換性**: 完全に保たれます

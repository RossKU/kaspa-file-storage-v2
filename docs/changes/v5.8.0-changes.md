# v5.8.0 変更内容

## UI再編成
システム初期化セクションをデバッグタブに移動し、作業フォルダのステータスを常時表示するようにしました。

### 主な変更点

#### 1. 作業フォルダステータスの常時表示
- アップロードタブの最上部に作業フォルダのステータスを常時表示
- 青い背景の枠内に表示（#2a3654）
- 設定済み: 緑色（#49EACB）で表示
- 未設定: 黄色（#ffcc66）で表示

#### 2. システム初期化セクションの移動
**移動した要素**：
- システム初期化ボタン
- 作業フォルダ設定ボタン
- 接続テストボタン
- 初期化ステータス表示（緑の枠）
- アドレスと残高の表示

**移動先**：デバッグタブの最上部

#### 3. デバッグタブのレイアウト改善
- システム初期化セクションを最上部に配置
- その下にデバッグログセクションを配置
- 論理的な構成に改善

## 技術的な変更

### HTML構造の変更
1. `workspaceStatusDisplay`要素を新規追加
2. システム初期化セクションをdebug-tabに移動
3. `showWorkspaceStatus()`関数を更新

### JavaScript変更
- `showWorkspaceStatus()`関数を新しい要素に対応
- DOMContentLoadedで自動的にステータスを表示

## 影響
- **ユーザビリティ向上**: 作業フォルダの状態が常に確認可能
- **UI整理**: 初期設定関連の機能をデバッグタブに集約
- **既存機能への影響**: なし

# v5.9.3 変更内容

## 概要
ファイルアクションバーのレイアウトを改善し、常時表示にしました。サイドバーの状態に応じて適切に配置されるようになりました。

## 主な変更点

### 1. ファイルアクションバーの常時表示
- **変更前**: ファイル選択時のみ表示
- **変更後**: 常に表示される

### 2. ボタンの中央揃え
- `justify-content: center` を追加
- ボタンが画面中央に配置される

### 3. サイドバー連動レイアウト
- **通常時**: `left: 240px`（サイドバー幅分のオフセット）
- **サイドバー折りたたみ時**: `left: 60px`
- **モバイル**: `left: 0`（サイドバーなし）
- `transition` による滑らかなアニメーション

### 4. コンテンツとの重複防止
- Fileタブのコンテナに `padding-bottom: 80px` を追加
- アクションバーとコンテンツが重ならない

## 技術的詳細

### CSS変更
```css
.file-actions {
    display: flex;  /* 常時表示 */
    justify-content: center;  /* 中央揃え */
    left: 240px;  /* サイドバー幅 */
    transition: left 0.3s ease;
}

.sidebar-collapsed .file-actions {
    left: 60px;  /* 折りたたみ時 */
}

#file-tab .container {
    padding-bottom: 80px;  /* 重複防止 */
}
```

### JavaScript変更
- `updateFileActions()` から表示/非表示の制御を削除
- 選択状態の管理のみに簡素化

## レスポンシブ対応
- デスクトップ: サイドバーの状態に応じて動的に調整
- タブレット: 同上
- モバイル: サイドバーなし、全幅表示

# v6.1.1 Changes - FileタブDownloadボタン修正

## 🔧 Fixed Issues

### 1. FileタブのDownloadボタンエラー修正
- **問題**: `Cannot read properties of undefined (reading 'find')`エラー
- **原因**: 存在しない`FileState.fileList`を参照していた
- **修正**: `FileState.kenvManager.entries`を使用するように変更（17692行目）

## ✨ Enhanced Features

### 2. Download機能の簡略化
- **変更前**: 
  - 複数ファイル選択可能
  - 自動的にダウンロード実行
  
- **変更後**:
  - 単一ファイル選択のみ
  - ダウンロードタブへ自動切り替え
  - TxID:BlockID:Password形式で自動入力
  - ユーザーが「Verify」ボタンをクリックして続行

## 📝 Technical Details

### 修正箇所
- `window.downloadSelected()`関数（17678-17733行目）

### 動作フロー
1. FileタブでファイルをCheckboxで選択
2. Downloadボタンをクリック
3. KENVエントリーからmetaTxID、blockID、passwordを取得
4. ダウンロードタブに自動切り替え
5. 統合入力欄（unifiedTxIdInput）に自動入力
6. ユーザーが「Verify」ボタンで検証を開始

## 🎯 Benefits
- エラーが解消され、正常に動作するように
- ユーザーがダウンロード前に内容を確認できる
- 誤操作によるダウンロード開始を防止
- よりシンプルで理解しやすいフロー

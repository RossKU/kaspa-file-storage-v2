# v6.1.4 Changes - Directory Builder エラー修正

## 🐛 Fixed Issues

### 1. toString() null参照エラー修正
- **場所**: 13300行目
- **問題**: ウォレット未接続時に`UserState.address.toString()`でnullエラー
- **修正**: `UserState.address?.toString() || null`
- **影響**: ディレクトリアップロード時のメタデータ生成エラーを解消

### 2. saveToStorage() 未定義関数エラー修正
- **場所**: 6553行目  
- **問題**: 存在しない`saveToStorage()`関数を呼び出し
- **修正**: `await FileState.kenvManager.saveAll()`
- **影響**: ディレクトリKENVエントリー保存エラーを解消

## 📝 Technical Details

### エラー発生状況
- ディレクトリビルダーでアップロード時に2つのエラーが連続発生
- 1つ目: メタデータ生成時にnull参照エラー
- 2つ目: BlockID取得成功後のKENV保存でundefined関数エラー

### 修正後の動作
- ウォレット未接続でもエラーなくメタデータ生成
- KENVエントリーが正しく保存される

## 🎯 Benefits
- ディレクトリアップロード機能の安定性向上
- エラーハンドリングの改善
- ユーザーエクスペリエンス向上

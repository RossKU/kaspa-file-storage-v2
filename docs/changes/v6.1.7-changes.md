# v6.1.7 Changes - RPC Client IP Address Display

## 🎯 Feature: Display RPC Client Connection IP

### What Changed
- RPC Client's connected node IP address is now displayed in Status tab
- Shows the actual WebSocket URL/IP that RPC Client is connected to
- IP address appears in the Node information line

### Technical Implementation
- Uses `NetworkState.rpcClient.url` property to get WebSocket URL
- Extracts IP address/hostname from the WebSocket URL
- Updates `updateRpcNodeInfo()` function to parse and display IP

### Display Format
**Before:** `Node: Testnet-10 • 1.0.1 • Synced • Standard (Auto)`
**After:** `Node: Testnet-10 • 1.0.1 • 95.217.118.5:17110 • Synced • Standard (Auto)`

### Benefits
- See which specific node RPC Client is connected to
- Verify connection details
- Debug connectivity issues
- Useful for archive node exploration

## 🔧 Technical Details
- Gets URL from `NetworkState.rpcClient.url`
- Parses WebSocket URL format: `ws://IP:PORT` or `wss://IP:PORT`
- Displays IP address with port number in Node status line

# v6.2.17 Changes - Fix Directory Upload Status Bug

## Date: 2025-08-19

## Issue
Directory uploaded via Directory Builder showed "未検証" (unverified) status in File tab despite successful upload with MetaTxID.

## Root Cause
After successful directory upload, the KENV entry status remained as 'pending' instead of being updated to 'verified'.

## Solution
Added status update to 'verified' after successful upload:
```javascript
// v6.2.17: Update status to verified after successful upload
kenvEntry.status = 'verified';
```

## Code Changes
- **Location**: Line 6815-6816 in DirectoryBuilderState.generateAndUpload()
- **Change**: Added `kenvEntry.status = 'verified';` after setting metadata

## Impact
- Directory entries now show "✅" (verified) status in File tab
- Consistent with regular file upload behavior

## Testing
- Upload directory via Directory Builder
- Check File tab shows verified status
- Confirm MetaTxID is displayed correctly

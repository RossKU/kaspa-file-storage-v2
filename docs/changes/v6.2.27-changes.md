# v6.2.27 Changes - Fix Date Column to Show Blockchain Upload Date

## Date: 2025-08-20

## Problem
The Date column in File tab was showing `entry.uploadDate` (when the entry was added to local KENV) instead of the actual blockchain upload date.

## Solution
Changed the Date column to reference `entry.created` which contains the actual upload timestamp from the blockchain metadata.

## Changes

### Modified Date Column Reference (line 18350)
```javascript
// Before:
const uploadDate = entry.uploadDate ? formatDate(entry.uploadDate) : '-';

// After:
const uploadDate = entry.created ? formatDate(entry.created) : '-';
```

## Impact
- Date column now shows the correct blockchain upload date
- Files added via "Add File" show their original upload date, not when they were added locally
- More accurate file history tracking

## Example
If someone uploaded a file on 2025-07-15 and you add it via "Add File" today:
- Before: Shows today's date (incorrect)
- After: Shows 2025-07-15 (correct)

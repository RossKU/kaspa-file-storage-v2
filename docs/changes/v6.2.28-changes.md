# v6.2.28 Changes - Fix File Information Dialog Date Display

## Date: 2025-08-20

## Problem
The File Information dialog was showing incorrect date fields:
- Upload Date was referencing non-existent field
- Created Date was referencing non-existent field

## Solution
Clarified the date fields with proper naming and references:
- **Upload Date**: Shows `file.created` (blockchain upload timestamp)
- **Add Date**: Shows `file.uploadDate` (when added to local KENV)

## Changes

### File Information Dialog (lines 19006-19007)
```javascript
// Before:
<strong>Upload Date:</strong> ${formatDate(file.uploadDate)}
<strong>Created Date:</strong> ${formatDate(file.createdAt)}

// After:
<strong>Upload Date:</strong> ${formatDate(file.created)}
<strong>Add Date:</strong> ${formatDate(file.uploadDate)}
```

## Impact
- Users can now see both dates clearly:
  - When the file was actually uploaded to blockchain
  - When the file was added to their local collection
- Better understanding of file history

## Example
For a file uploaded on 2025-08-15 and added via "Add File" on 2025-08-20:
- Upload Date: 2025-08-15 (blockchain upload)
- Add Date: 2025-08-20 (local addition)

## 修正内容

### log関数の3引数対応
**場所**: index.html line 3985-4041

**変更前**:
```javascript
window.log = function log(message, type = 'info') {
    // 2引数のみ対応
}
```

**変更後**:
```javascript
window.log = function log(message, type = 'info', detail = null) {
    // 3引数対応、detailパラメータを適切に処理
}
```

### 主な機能追加

1. **第3引数（detail）のサポート**
   - null以外の値が渡された場合に処理
   - 後方互換性を保持（detailはオプション）

2. **オブジェクトの文字列化**
   - JSON.stringifyで整形（2スペースインデント）
   - 単行の場合はインライン表示
   - 複数行の場合は改行して表示

3. **エラーハンドリング**
   - Errorオブジェクトの特別処理
   - スタックトレースの表示
   - 循環参照の対処

4. **HTMLエスケープ処理**
   - セキュリティ向上
   - 改行文字の適切な処理

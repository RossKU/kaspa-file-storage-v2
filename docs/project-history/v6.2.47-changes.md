# v6.2.47: Simplify sort options in File tab

## Changed
- **Removed unused sort options**:
  - Removed CID sort (too technical, not useful for most users)
  - Removed Uploader sort (uploaderId field doesn't exist)
  - Removed Created sort (createdAt field doesn't exist, duplicates Upload Date)
  - Removed desktop-only class distinction

- **Streamlined sort options to 4 essential ones**:
  - Name (ascending/descending)
  - Size (ascending/descending) 
  - Upload Date (ascending/descending)
  - MetaTxID (ascending/descending)

## Technical Details
- Removed non-functional sort cases from sortKENVFiles function
- These sort options were referencing non-existent fields (uploaderId, createdAt)
- Simplified codebase by removing ~30 lines of unused code

## UI Improvements
- Cleaner, more focused sort dropdown
- Only shows options that actually work
- Better user experience with fewer confusing options

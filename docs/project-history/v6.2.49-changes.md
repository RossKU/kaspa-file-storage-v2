# v6.2.49: Directory Builder Cascade Deletion

## Problem
When deleting a parent folder in Directory Builder, child folders and files were not being deleted, leaving orphaned entries in the tree structure.

## Solution
Implemented cascade deletion in the `removeEntry()` method that automatically removes all child entries when a parent folder is deleted.

## Implementation Details

### `removeEntry(index)` Method (lines 7083-7143)
1. **Parent Detection**: Identifies if the entry being deleted is a directory
2. **Child Discovery**: Finds all entries whose path starts with the parent's path
3. **Cascade Deletion**: Removes parent and all children in correct order
4. **Logging**: Console logs show which entries are being removed

### Deletion Logic
```javascript
// For directory deletion:
// 1. Build list of all entries to remove (parent + children)
// 2. Sort indices in descending order (remove from end to start)
// 3. Remove all entries
// 4. Update UI and show status
```

## Features
- ✅ Deleting a folder removes all its contents
- ✅ Works with nested folder structures
- ✅ Handles both direct children and deeply nested items
- ✅ Shows count of deleted items in status message
- ✅ Console logging for debugging

## Example
```
folder1/           <- Delete this
```

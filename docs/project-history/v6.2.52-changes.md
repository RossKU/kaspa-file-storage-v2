# v6.2.52: Add refresh balance functionality to Wallet & UTXO Management

## Features Added
- Added refresh balance button in Settings tab > Wallet & UTXO Management section
- Button appears after successful wallet connection
- Provides real-time balance and UTXO count updates

## Implementation Details

### UI Changes (lines 2301-2315)
- Added "🔄 Refresh" button next to balance display
- Button initially hidden, shown only when wallet is connected
- Responsive layout using flexbox for proper alignment

### Functionality (lines 3117-3191)
- New `refreshWalletBalance()` function
- Fetches latest UTXOs from blockchain
- Updates balance and UTXO count displays
- Updates consolidation button state
- Provides visual feedback during operation:
  - ⏳ Loading state while fetching
  - ✅ Success confirmation
  - ❌ Error indication

### Integration
- Show button on wallet connection (line 3747-3751)
- Hide button on wallet disconnection (line 1630-1634)

## User Experience
- **Loading state**: Button shows "⏳ Loading..." while fetching data
- **Success state**: Shows "✅ Updated" for 2 seconds
- **Error state**: Shows "❌ Error" if refresh fails
- **Auto-recovery**: Button returns to normal state after 2 seconds

## Technical Features
- Prevents multiple simultaneous refreshes (button disabled during operation)
- Comprehensive error handling
- Logs all operations for debugging
- Maintains consistency with existing balance update logic
- Works with both testnet and mainnet

## Benefits
- Manually refresh balance without reconnecting wallet
- Verify balance after transactions
- Check UTXO count before large uploads
- Ensure latest blockchain state is reflected

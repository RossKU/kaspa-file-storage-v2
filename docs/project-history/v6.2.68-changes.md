# v6.2.68 Changes - Meta Transaction Retry Logic

## 🔧 Enhancement
Added retry logic to meta transaction submission, matching the pattern used by regular chunks.

### Problem
When WebSocket disconnected during meta transaction submission, the transaction would fail immediately without retry, unlike regular chunks which have retry logic.

### Solution
Implemented the same retry pattern as regular chunks:
- While loop with max 3 retries (config.retryCount)
- Fresh UTXO fetching on each retry (implicit connection check)
- 2-second wait between retries to allow ConnectionManager to reconnect
- Proper error handling for WebSocket disconnects

### Technical Details

### Impact

- Consistent behavior with regular chunk uploads
- Better reliability during network instability

# v6.2.74 Changes - Fix Orphaned Meta-tx BlockID Waiting Loops

## 🐛 Critical Bug Fix

Fixed orphaned BlockID waiting loops for meta transactions - old loops are now properly cancelled when re-starting meta-tx processing.

### Problem (Identified in Recovery Log Analysis)

When meta-tx creation was interrupted and auto-resumed:
1. Initial meta-tx send → BlockID waiting loop A starts
2. WebSocket disconnects → Loop A continues
3. Reconnection + auto-resume
4. New meta-tx send → BlockID waiting loop B starts
5. **Loop A remains active** → REST API spam every 500ms

### Root Cause

Meta-tx is called as an independent function (unlike regular chunks in a for loop):
- Can be called multiple times (initial + resume)
- No cancellation mechanism for old loops
- Results in multiple parallel BlockID waiting loops

### Solution Implementation

Added AbortController pattern to properly manage loop lifecycle:

#### 1. FileState Enhancement (Line 4470)
```javascript
metaTxAbortController: null,  // v6.2.74: AbortController for meta-tx BlockID waiting loop
```

#### 2. Cancel Old Loops (Line 14630-14638)
```javascript
// Cancel any existing meta-tx BlockID waiting loop
if (FileState.metaTxAbortController) {
    FileState.metaTxAbortController.abort();
    FileState.metaTxAbortController = null;
}
// Create new AbortController for this session
FileState.metaTxAbortController = new AbortController();
```

#### 3. Check Abort Signal in Loop (Line 14941-14945)
```javascript
// Check if this loop should be aborted
if (FileState.metaTxAbortController?.signal.aborted) {
    log('[DEBUG] メタTx BlockID待機がキャンセルされました', 'debug');
    return;
}
```

#### 4. Handle Abort in Delay (Line 14991-15017)
```javascript
await new Promise((resolve, reject) => {
    const timeout = setTimeout(resolve, 500);
    
    if (FileState.metaTxAbortController?.signal.aborted) {
        clearTimeout(timeout);
        reject(new DOMException('Aborted', 'AbortError'));
        return;
    }
    
    FileState.metaTxAbortController?.signal.addEventListener('abort', () => {
        clearTimeout(timeout);
        reject(new DOMException('Aborted', 'AbortError'));
    }, { once: true });
});
```

#### 5. Cleanup on Completion
- Success: Line 15090-15094
- Error: Line 15099-15103
- Super meta case: Line 14772-14776
- Max chunks exceeded: Line 14662-14665

## 📝 主要機能

### 1. サブディレクトリ完全サポート

#### 現状の課題
- エントリーは`type: 'file'`のみ
- フラットなディレクトリ構造

#### 実装内容
```javascript
{
  "name": "documents",
  "path": "project/documents",
  "type": "directory",  // 新規サポート
  "fileCount": 10,
  "totalSize": 1024000,
  "cid": "bafybeif..."
}
```

#### 利点
- 完全なフォルダ構造の保持
- 効率的なファイル管理
- 大規模プロジェクトのサポート

### 2. メタデータチャンク化

#### 現状の制限
- 20KBまでのメタデータサイズ制限
- 約133ファイルまで

#### 解決策
```javascript
// メタデータを複数のチャンクに分割
async function uploadChunkedDirectoryMetadata(metadata) {
  const chunks = splitMetadata(metadata, 19 * 1024); // 19KB chunks
  const chunkTxIds = [];
  
  for (const chunk of chunks) {
    const result = await uploadChunk(chunk);
    chunkTxIds.push(result.txid);
  }
  
  // ルートメタデータにチャンクIDを記録
  return createRootMetadata(chunkTxIds);
}
```

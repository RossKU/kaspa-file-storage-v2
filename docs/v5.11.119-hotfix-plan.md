# v5.11.119 Hotfix計画（Ultrathink）

## バグの詳細

### 問題箇所（14564-14570行）
```javascript
archiveClient = await NetworkState.archiveManager.getOptimalClient();
// archiveClientがnullの可能性
const switched = archiveClient !== null;
if (switched) {
    // archiveClientがnullでもここに入る可能性
    const blockResponse = await archiveClient.getBlock({  // NULL参照エラー！
```

### 根本原因
- `switchToArchiveNode()`削除時のエラーハンドリング不足
- アーカイブノードが未接続時のnullチェック不足
- WASMエラーの連鎖で「disconnected from all chains」メッセージ

## 修正方針

### Option A: 最小限の修正（推奨）
```javascript
if (switched && archiveClient) {  // nullチェック追加
    try {
        const blockResponse = await archiveClient.getBlock({
            hash: blockId,
            includeTransactions: true
        });
        // ... 処理続行
    } catch (archiveError) {
        log(`[RPC] アーカイブノードでもエラー: ${archiveError.message}`, 'error');
        throw rpcError; // 元のエラーを再throw
    }
} else {
    log(`[RPC] 利用可能なアーカイブノードがありません`, 'warning');
    throw rpcError;
}
```

🦀 Rusty Kaspa公式WASMファイル取得

重要: 現在のkaspa-core.jsとkaspa-core_bg.wasmが不一致の可能性があります。 公式リポジトリから正しいペアを取得しましょう。

方法1: 最新の安定版リリース（推奨）

Rusty Kaspa v0.15.x の最新リリースから：

# 最新リリースのWASMパッケージ wget https://github.com/kaspanet/rusty-kaspa/releases/download/v0.15.2/kaspa-wasm-nodejs-v0.15.2.zip unzip kaspa-wasm-nodejs-v0.15.2.zip # またはブラウザ版 wget https://github.com/kaspanet/rusty-kaspa/releases/download/v0.15.2/kaspa-wasm-v0.15.2.zip unzip kaspa-wasm-v0.15.2.zip

方法2: NPMから（最も簡単）

# バックアップ mv kaspa-core.js kaspa-core.js.old mv kaspa-core_bg.wasm kaspa-core_bg.wasm.old # NPMから直接ダウンロード curl -o kaspa-core.js https://unpkg.com/@kaspa/core-lib@0.15.2/kaspa-core.js curl -o kaspa-core_bg.wasm https://unpkg.com/@kaspa/core-lib@0.15.2/kaspa-core_bg.wasm

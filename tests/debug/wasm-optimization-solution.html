問題の原因: 巨大なWASMファイル（11.4MB）

⚠️ 根本原因

kaspa-core_bg.wasm が 11.4MB と巨大すぎます。これが全ての遅延の原因です。

  • 毎回11.4MBをダウンロード
  • プライベートモードではキャッシュが効かない
  • GitHub Pages等では配信が特に遅い

解決策1: WASM遅延読み込み + プログレス表示

// index.htmlの冒頭に追加 let wasmLoaded = false; let wasmLoading = false; async function loadWasmWithProgress() { if (wasmLoaded || wasmLoading) return; wasmLoading = true; // プログレス表示 const progress = document.createElement('div'); progress.id = 'wasm-progress'; progress.style.cssText = ` position: fixed; top: 50%; left: 50%; transform: translate(-50%, -50%); background: #2A6F65; color: white; padding: 30px; border-radius: 8px; z-index: 10000; text-align: center; box-shadow: 0 4px 6px rgba(0,0,0,0.3); `; progress.innerHTML = `

初回起動準備中...

WASMファイル読み込み中 (11.4MB)

0%

`; document.body.appendChild(progress); try { // JSファイル読み込み const response = await fetch('kaspa-core.js'); const blob = await response.blob(); const script = document.createElement('script'); script.src = URL.createObjectURL(blob); await new Promise((resolve) => { script.onload = resolve; document.head.appendChild(script); }); // WASM初期化（プログレス付き） await init({ // プログレスコールバック progress: (loaded, total) => { const percent = Math.round((loaded / total) * 100); document.getElementById('progress-bar').style.width = percent + '%'; document.getElementById('progress-text').textContent = percent + '%'; } }); wasmLoaded = true; progress.remove(); } catch (e) { progress.innerHTML = `

読み込みエラー

${e.message}

`; setTimeout(() => progress.remove(), 3000); } wasmLoading = false; } // 必要な時だけ読み込み async function connectToRPC() { await loadWasmWithProgress(); // その後RPCに接続 }

解決策4: 分割読み込み（推奨）

// WASMを機能別に分割 const modules = { core: 'kaspa-core-essential.wasm', // 2MB - 必須機能のみ crypto: 'kaspa-crypto.wasm', // 3MB - 暗号化機能 mining: 'kaspa-mining.wasm' // 残り - マイニング機能 }; // 必要な機能だけ読み込み async function loadEssentialOnly() { await init(modules.core); // ファイル操作には必須機能のみで十分 }

📊 影響の詳細

  • 初回読み込み: 11.4MB ÷ 1Mbps = 約91秒
  • 通常の接続(10Mbps): 約9秒
  • 高速接続(100Mbps): 約0.9秒

昨日は正常 → 今日は遅い の理由:

  • 昨日: ブラウザキャッシュが効いていた
  • 今日: キャッシュがクリアされた or 期限切れ

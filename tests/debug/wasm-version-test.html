WASM/ライブラリバージョン問題の可能性

🎯 最も可能性の高い原因

kaspa-core.js / kaspa-core_bg.wasm のバージョン問題

症状が一致：

  • 昨日まで正常 → 今日から全バージョン遅い
  • 別IP、別環境でも同じ
  • ローカルサーバーでも同じ
  • 特定のRPCメソッドだけ遅い

考えられるシナリオ：

  1. WASMファイルが外部CDNから読み込まれている
  2. そのCDNのWASMが更新された
  3. 新しいWASMに特定のメソッドのバグがある

確認方法

// コンソールで実行
console.log(typeof RpcClient);
console.log(RpcClient.prototype.getBlock.toString());

// WASMのバージョン確認
if (window.__wasm_version) {
    console.log('WASM Version:', window.__wasm_version);
}

解決策

  1. 古いバージョンのWASMファイルを使用
  2. 異なるKaspaライブラリを使用
  3. 直接REST APIを使用（WASMを回避）

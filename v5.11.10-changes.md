# v5.11.10 Changes - REST API Health Check Display

## Changes
1. **Added REST API status display**
   - Shows REST API availability for fallback
   - Displays endpoint URL (api-tn10.kaspa.org or api.kaspa.org)
   - Shows response time in milliseconds
   - Located below Archive Node section as it's a fallback option

2. **New function checkRestApiHealth()**
   - Performs health check on `/info/health` endpoint
   - Updates UI with connection status
   - Shows green indicator when ready
   - Shows red indicator when not available

3. **Health check triggers**
   - Initial system connection
   - RPC reconnection
   - ConnectionManager recovery
   - No periodic checks (only on connection events)

4. **Display states**
   - Ready: "REST API: 🟢 Ready" with response time
   - Error: "REST API: 🔴 Error" with HTTP status
   - Not Available: "REST API: 🔴 Not Available" (timeout/network error)

## Purpose
- Provides visibility into REST API fallback availability
- Helps users understand if fallback is available when RPC fails
- Shows performance metrics (response time)
- Complements RPC status for complete network visibility

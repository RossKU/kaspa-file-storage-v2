# v5.11.102 変更内容 - ネットワーク切り替え時の再接続処理

## 実施日時
2025-08-02

## 変更内容
設定タブでネットワークを切り替えた際に、ウォレットとRPC接続をリセットする

## 背景
- 設定タブでテストネット→メインネットに切り替えても、接続が古いネットワークのまま維持される問題
- ウォレットアドレスが古いネットワーク用のまま表示される問題

## 実装内容

### networkSelectのchangeイベントハンドラーを修正（15238行付近）
```javascript
document.getElementById('networkSelect').addEventListener('change', async (e) => {
    const previousNetwork = config.network;
    config.network = e.target.value;
    log(`ネットワーク変更: ${previousNetwork} → ${config.network}`, 'info');
    
    // v5.11.102: ネットワーク変更時は接続をリセット
    if (previousNetwork !== config.network) {
        // 1. ウォレットを切断
        if (UserState.address) {
            AppState.disconnectWallet();
            log('ネットワーク変更のためウォレットを切断しました', 'info');
        }
        
        // 2. RPC接続をリセット
        if (NetworkState.rpcClient) {
            try {
                await NetworkState.rpcClient.disconnect();
                NetworkState.rpcClient = null;
                log('既存のRPC接続を切断しました', 'info');
                
                // 3. 新しいネットワークで再接続
                await initializeRpcClient();
                log('新しいネットワークでRPC接続を確立しました', 'success');
            } catch (error) {
                log(`RPC再接続エラー: ${error.message}`, 'error');
            }
        }
    }
    
    // 既存の処理（そのまま維持）
    // Update archive network display
    // Update ArchiveNodeManager
});
```

## 結果
- ネットワーク切り替え時にウォレットが自動的に切断される
- RPC接続が新しいネットワークで再確立される
- ユーザーは新しいネットワークでウォレットを再接続する必要がある

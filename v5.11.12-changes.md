# v5.11.12 Changes - Dev Wallet Toggle and Wallet Connection Fix

## Changes

### 1. Dev Wallet Toggle Feature
- **Added Dev Wallet toggle in Debug tab**
  - Yellow highlighted box for visibility
  - Shows "開発用ウォレット (b7e15162...)"
  - Toggle state persisted in localStorage
  - ON by default for backward compatibility

- **Conditional wallet initialization**
  - Only initializes test private key when Dev Wallet is enabled
  - Shows warning when disabled: "手動でウォレットを接続してください"
  - Automatically disconnects if using dev wallet when toggle is turned off

### 2. Wallet Connection Fix
- **Fixed API usage in connectWallet()**
  - Removed incorrect: `derivePublicKey()` and `publicKeyToAddress()`
  - Now uses correct: `new NetworkState.kaspa.PrivateKey(privateKey)`
  - Properly creates public key and address

- **Added disconnect functionality**
  - Connection button toggles between "接続" and "切断"
  - Clears private key and address on disconnect
  - Updates all related UI elements

### 3. UI Improvements
- **Status display updates**
  - Shows "Dev Wallet使用中" warning when using test key
  - Shows "ウォレット未接続" when no wallet connected
  - Upload button disabled when no wallet connected

- **Better error handling**
  - Clear error messages for connection failures
  - Proper state management for wallet connection

## Technical Details
- Added `AppState.settings.devWalletEnabled` flag
- LocalStorage key: `kaspaDevWalletEnabled`
- Fixed balance calculation using correct API
- Proper cleanup on disconnect

## Purpose
- Allows developers to easily toggle between dev wallet and manual connection
- Fixes broken wallet connection functionality
- Improves security by not forcing test private key usage
- Better user experience with clear connection states

# v5.11.14 Changes - Manual Wallet Connection Improvement

## Changes
- **Automatic Dev Wallet Disable on Manual Connection**
  - When connecting with a manual private key, Dev Wallet is automatically disabled
  - Dev Wallet toggle switch updates to OFF state
  - Prevents confusion between Dev Wallet and manual wallet

## Implementation Details

### 1. New AppState Method
- `AppState.disableDevWallet()` - Disables Dev Wallet and updates UI
  - Sets `AppState.settings.devWalletEnabled = false`
  - Updates localStorage
  - Updates toggle switch UI
  - Logs the action

### 2. connectWallet Function Enhancement
- **Dev Wallet Detection**: Checks if current wallet is Dev Wallet
- **Smart Disconnection**: 
  - If Dev Wallet is connected, disconnects and continues with manual connection
  - If manual wallet is connected, disconnects and stops (toggle behavior)
- **Auto-disable**: Calls `AppState.disableDevWallet()` after successful manual connection

## User Experience
1. **Dev Wallet → Manual Wallet**: Seamless transition
   - Enter private key and click connect
   - Dev Wallet disconnects automatically
   - Manual wallet connects
   - Dev Wallet toggle turns OFF

2. **Manual Wallet → Disconnect**: Toggle behavior maintained
   - Click connect button again to disconnect
   - No change to Dev Wallet setting

## Technical Architecture
- Follows existing State management pattern
- All Dev Wallet logic encapsulated in AppState
- No window pollution with individual functions
- Clean separation of concerns

# v5.11.7 Changes - REST API Test Mode & Automatic Fallback

## Changes
1. **Added REST API test mode for DownloadManager**
   - New `forceRestApi` flag to skip RPC and use REST API only
   - `toggleRestApiMode()` method to enable/disable test mode
   
2. **UI enhancements**
   - Added "REST APIテストモード" toggle in download settings
   - Shows warning when enabled, success message when disabled
   
3. **Automatic REST API fallback for all download methods**
   - `downloadPayload()`: Now falls back to REST API when RPC fails
   - `downloadChunk()`: Now falls back to REST API when RPC fails
   - Both methods handle chunk processing identically in fallback mode
   
4. **Implementation details**
   - Modified `fetchMetadata()` to skip RPC when test mode is enabled
   - Modified `downloadPayload()` with full REST API fallback
   - Modified `downloadChunk()` with full REST API fallback
   - Modified `ParallelDownloader.workerRaw()` to check test mode flag

## Purpose
This feature provides:
- Automatic fallback when RPC nodes are unavailable
- Manual testing mode for REST API performance
- Unified error handling across all download types (normal, directory, supermeta)
- Better reliability for file downloads

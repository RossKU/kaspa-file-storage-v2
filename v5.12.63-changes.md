# v5.12.63: モバイルアップロードボタン修正

## 問題
- デスクトップではアップロードボタンがクリック可能
- モバイルではアップロードボタンが有効になってもクリックできない

## 原因
- インラインonclickイベント（`onclick="processAndUpload()"`）がモバイルで動作しない場合がある
- タッチイベントとの相性問題

## 修正内容

### 1. インラインonclickを削除（1996行目）
```html
<!-- 修正前 -->
<button onclick="processAndUpload()" id="uploadBtn" disabled>

<!-- 修正後 -->
<button id="uploadBtn" disabled>
```

### 2. addEventListenerで設定（16185-16194行目）
```javascript
// v5.12.63: Add upload button event listener for mobile compatibility
const uploadBtn = document.getElementById('uploadBtn');
if (uploadBtn) {
    uploadBtn.addEventListener('click', async (e) => {
        e.preventDefault();
        if (!uploadBtn.disabled && typeof processAndUpload === 'function') {
            await processAndUpload();
        }
    });
}
```

## 効果
- モバイルでもアップロードボタンが正常にクリック可能
- ボタンが無効の場合は実行されない
- processAndUpload関数が定義されているか確認してから実行

# v6.1.8 Changes - Directory Upload WebSocket Monitoring Fix

## 🐛 Fixed: WebSocket Monitoring Not Stopping After Directory Upload

### Problem
- WebSocket monitoring continued running after directory upload completion
- Auxiliary RPCs remained connected
- 5-minute timer was not cleared
- Caused by `chunks=-1` not being handled in stop conditions

### Solution
Added specific stop condition for directory uploads:
```javascript
if (FileState.uploadingDirMeta === false && FileState.uploadingChunksCount === -1) {
    // Directory upload completed
    stopMonitoring();
    // Stop auxiliary RPCs
    // Clear 5-minute timer
}
```

### Technical Details
- `chunks=-1` is specific to directory metadata uploads (no chunk data)
- Regular file uploads use `chunks >= 0`
- Directory condition is checked before regular file conditions
- No impact on existing file upload stop conditions

### Benefits
- Proper resource cleanup after directory uploads
- Prevents WebSocket connection leaks
- Stops unnecessary auxiliary RPC connections
- Clears timers to prevent memory leaks
- Reduces battery consumption on mobile devices

## Impact
- Affects only Directory Builder uploads
- No impact on regular file uploads
- No impact on meta uploads or super meta uploads
- Backwards compatible

# v6.2.1 Changes - Directory Builder Pre-upload Checks

## 🎯 Feature: Pre-upload validation for Directory Builder

### What Changed
- Added wallet connection check before upload
- Added network connection check before upload
- Improved error messages with clear user feedback
- All error messages translated to English

### Technical Implementation

#### 1. Pre-upload Checks
Added validation before attempting upload:
- **Wallet Check**: Verifies `UserState.address` and `UserState.privateKey`
- **Network Check**: Verifies `NetworkState.rpcClient` and `NetworkState.kaspa`

#### 2. Error Message Flow
```
User clicks [Generate and Upload]
↓
Check wallet → "Wallet not connected" (if not connected)
↓
Check network → "Network not connected" (if not connected)
↓
Check password → "Password must be at least 8 characters"
↓
Proceed with upload
```

#### 3. English Translations
- パスワードは8文字以上で入力してください → Password must be at least 8 characters
- 生成エラー → Generation error
- ディレクトリメタデータサイズ → Directory metadata size
- 利用可能なUTXOがありません → No available UTXOs
- トランザクションの作成に失敗しました → Failed to create transaction

### User Experience Improvements
- **Immediate feedback**: Errors shown instantly (no deep null reference errors)
- **Clear messages**: User knows exactly what's wrong
- **Action-oriented**: Tells user what to do (connect wallet, connect network)
- **Consistent UI**: Uses existing showStatus() display

### Error Prevention
- Prevents `Cannot read properties of null` errors
- Catches issues before transaction creation
- Reduces confusion and support requests

### Files Modified
- `index.html`: Added pre-checks, translated error messages

- Updated from v6.2.0 to v6.2.1

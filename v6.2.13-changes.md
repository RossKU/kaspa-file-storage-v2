# v6.2.13 Changes - Proactive UTXO Warning in Upload Estimate

## 🔧 Preventive UTXO Management

### Problem
- Storage mass errors occur during upload when UTXO count is too high
- Users only find out after upload starts and fails
- UTXO consolidation is better done before upload

### Solution
- Check UTXO count during upload estimate
- Show warning if UTXOs > 40
- Recommend consolidation before continuing
- Let user make informed decision

## Implementation Details

### UTXO Check Added to Estimate
```javascript
// Check UTXO count for warning
const { entries } = await NetworkState.rpcClient.getUtxosByAddresses([UserState.address.toString()]);
const utxoCount = entries.length;

if (utxoCount > 40) {
    // Add warning to confirmation message
}
```

### Warning Message
- Shows current UTXO count
- Warns about potential "Storage mass exceeded" errors
- Directs to Debug tab → UTXO Management
- User can still proceed if they want

## Key Insight
- UTXOs don't increase easily after consolidation
- Once reduced, they stay low for a long time
- Better to warn before upload than handle errors during

## User Experience
1. Start upload → Estimate shown
2. If UTXOs > 40 → ⚠️ Warning appears
3. User decides: Consolidate first or proceed
4. Prevents mid-upload failures

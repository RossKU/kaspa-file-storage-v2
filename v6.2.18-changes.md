# v6.2.18 Changes - Add directoryMetadata for File Tab Display

## Date: 2025-08-19

## Issue
Directory entries in File tab showed "Directory" in size column instead of file/folder counts.

## Root Cause
`directoryMetadata` was not being saved to KENV entry, but File tab display logic expected it to show file counts.

## Solution
Added directoryMetadata to KENV entry after successful upload:
```javascript
// v6.2.18: Add directoryMetadata for File tab display
kenvEntry.directoryMetadata = metadata;
```

## Code Changes
- **Location**: Line 6818-6819 in DirectoryBuilderState.generateAndUpload()
- **Change**: Store complete metadata object as directoryMetadata

## Impact
- File tab now shows "X files, Y dirs" in size column for directories
- Complete directory structure is preserved in KENV

## Testing
- Upload directory via Directory Builder
- Check File tab shows file/folder counts in size column
- Verify directory can be downloaded with full structure

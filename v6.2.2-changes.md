# v6.2.2 Changes - UTXO Management Feature (Phase 1)

## 🎯 Feature: UTXO Consolidation Functionality

### What's New
- **UTXO Management UI** in Debug tab
- **Check UTXO Status** button to view current UTXO count and balance
- **Consolidate UTXOs** button to combine multiple UTXOs into one
- Automatic warning when UTXO count exceeds 40

### Purpose
Prevent "Storage mass exceeded" errors during file uploads by consolidating multiple UTXOs before they reach critical levels.

### Technical Implementation

#### 1. UI Components (Debug Tab)
- **UTXO Status Display**
  - Current UTXO count
  - Total balance in KAS
  - Warning message when count > 40
- **Action Buttons**
  - Check UTXO Status: Fetches current UTXO information
  - Consolidate UTXOs: Creates empty transaction to combine UTXOs

#### 2. Core Functions
```javascript
// Check current UTXO status
DebugHandlers.checkUTXOStatus()
- Fetches UTXOs from blockchain
- Calculates total balance
- Updates UI with count and balance
- Shows warning if count > 40

// Consolidate multiple UTXOs
DebugHandlers.consolidateUTXOs()
- Creates empty transaction (no payload)
- Uses all UTXOs as inputs
- Sends consolidated amount back to wallet
- Fee: 0.0001 KAS
```

#### 3. Integration Points
- Uses existing `NetworkState.rpcClient` for blockchain queries
- Uses existing `UserState.address` and `UserState.privateKey`
- Uses existing `NetworkState.kaspa` for transaction creation
- Follows existing DebugHandlers pattern

### User Experience
1. Navigate to Debug tab
2. Click "Check UTXO Status" to see current state
3. If warning appears (>40 UTXOs), click "Consolidate UTXOs"
4. Wait for transaction confirmation
5. UTXO count will be reduced to 1-2 after consolidation

### Error Handling
- Wallet not connected error
- Network not connected error
- Transaction creation failure
- Transaction submission failure
- All errors displayed in UI with clear messages

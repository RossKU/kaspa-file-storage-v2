# v6.2.21 Changes - Fix UTXO Consolidation Cost Display
## Date: 2025-08-19

## Problem
The UTXO consolidation cost was incorrectly displayed as "~0.0003 KAS" which was inaccurate.

## Analysis
Based on actual transaction logs:
- Transaction 1: 130 UTXOs → 43 UTXOs (87 consolidated) = 0.00099402 KAS fee
- Transaction 2: 43 UTXOs → 5 UTXOs (38 consolidated) = 0.00045638 KAS fee

### Calculation:
- Per UTXO cost (1st): 0.00099402 ÷ 87 = 0.00001143 KAS
- Per UTXO cost (2nd): 0.00045638 ÷ 38 = 0.00001201 KAS
- Average: ~0.000011 KAS per UTXO consolidated

## Changes
### Settings Tab 
1. **Line 2287**: File size threshold
   - Before: `Essential for large file uploads (>550MB)`
   - After: `Essential for large file uploads (>1MB)`

2. **Line 2288**: Cost display
   - Before: `Cost: Only network fees (~0.0003 KAS)`
   - After: `Cost: ~0.000011 KAS per UTXO consolidated`

## Impact
Users now see accurate cost information based on real measurements. The cost scales with the number of UTXOs being consolidated (e.g., ~0.0011 KAS for 100 UTXOs).

## Note
The 99% send amount is intentional design - only 1% returns to the same wallet to consolidate UTXOs. The actual network fee is separate and much smaller.

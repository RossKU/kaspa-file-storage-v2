# v6.2.25 Changes - Fix "Loading..." Issue in Add File Feature

## Date: 2025-08-20

## Problem
When adding files via "Add File" button with TxID:BlockID:Pass, the file name stayed as "Loading..." even after verification completed.

## Root Cause
The `verifyAndCompleteEntry` function only changed the status to 'verified' without fetching actual metadata from the blockchain.

## Solution
Added `fetchMetadata` call to retrieve file information from blockchain and update entry with:
- Actual file name
- File size
- File type
- Creation date
- Network information

## Changes

### Modified `verifyAndCompleteEntry` function (lines 5329-5380)
- Added NetworkState check
- Added fetchMetadata call
- Extract basic information from metadata
- Update entry.name (fixes "Loading..." issue)
- Auto-update UI after verification

### Error Handling
- Graceful fallback if metadata fetch fails
- Entry still marked as verified even if metadata unavailable
- Warning message stored in entry.authWarning

## Impact
- Add File feature now properly displays file names
- File sizes are shown correctly
- Directory entries show file/folder counts
- Better user experience with real-time updates

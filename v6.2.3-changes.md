# v6.2.3 Changes - UTXO Management Bug Fixes

## 🐛 Bug Fixes

### Fixed: UTXO Status Check Error
- **Problem**: `Cannot read properties of undefined (reading 'amount')` error
- **Cause**: Incorrect property access `entry.utxoEntry.amount`
- **Solution**: Changed to `entry.amount` matching SDK API structure

### Fixed: UTXO Consolidation Transaction Creation
- **Problem**: Empty transaction creation failed
- **Cause**: Not providing UTXOs as entries to createTransactions
- **Solution**: 
  - Fetch and format all UTXOs
  - Calculate total balance
  - Create self-send transaction with all UTXOs as inputs
  - Send consolidated amount (total - fee) back to wallet

### Technical Changes

#### checkUTXOStatus() Fix
```javascript
// Before (incorrect)
totalBalance += entry.utxoEntry.amount;

// After (correct)
totalBalance += BigInt(entry.amount);
```

#### consolidateUTXOs() Fix
```javascript
// Before (incorrect)
const result = await NetworkState.kaspa.createTransactions({
    entries: [],  // Empty - won't work
    outputs: [],
    ...
});

// After (correct)
const { entries } = await NetworkState.rpcClient.getUtxosByAddresses(...);
const formattedUtxos = entries.map(utxo => ({
    address: UserState.address.toString(),
    outpoint: { transactionId: utxo.outpoint.transactionId, index: utxo.outpoint.index },
    scriptPublicKey: utxo.scriptPublicKey,
    amount: BigInt(utxo.amount),
    ...
}));
const result = await NetworkState.kaspa.createTransactions({
    entries: formattedUtxos,  // All UTXOs as inputs
    outputs: [{
        address: UserState.address.toString(),
        amount: consolidatedAmount  // Total minus fee
    }],
    ...
});
```

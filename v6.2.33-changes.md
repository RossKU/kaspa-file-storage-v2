# v6.2.33 Changes - Add "File List Only" Option to Download Tab

## Date: 2025-08-20

## Feature
Added "Add to File List only (without downloading)" checkbox option to the Download tab, allowing users to add files to their KENV file list without actually downloading them.

## Problem
Previously, the File tab's "Add File" feature only accepted TxID:BlockID:Password format. Users wanted the same flexibility as the Download tab, which supports multiple input formats:
- TxID:BlockID:Password (recommended)
- TxID:BlockID (with separate password)
- TxID only (uses REST API)

## Solution
Instead of duplicating the parsing logic in the File tab, added a checkbox to the Download tab that:
1. Fetches metadata from blockchain
2. Creates KENV entry for file management
3. Skips the actual download process
4. Automatically switches to File tab

<label for="addToListOnly">📋 Add to File List only (without downloading)</label>
```

### 2. executeDownload Function (line 10441)

const { ..., addToListOnly = false } = options;
```

### 3. Download Skip Logic (lines 10447-10910)
Wrapped download processing in `if (!addToListOnly)` block:
- Skips chunk downloads
- Skips file decryption
- Skips blob creation and file save

### 4. loadFromUnifiedInput Function (line 15263)
Gets checkbox state and passes it through:

```

### 5. Auto-switch to File Tab (lines 15146-15151)
After successful KENV registration, switches to File tab:

    const fileTab = document.querySelector('[onclick*="switchTab(\'file\')"]');

}
```

## Impact
- Users can now add any blockchain file to their local management without downloading
- Saves bandwidth and storage space
- Uses all existing input format parsing from Download tab
- File tab's "Add File" button can potentially be removed (duplicate functionality)

## Benefits
- Consistent input handling across the application
- Reuses existing metadata fetching and KENV registration logic
- Better user experience with automatic tab switching
- Resource-efficient file management

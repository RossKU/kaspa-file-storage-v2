# v6.2.35 Changes - Fix Add to File List Only KENV Registration

## Date: 2025-08-21

## Problem
The "Add to File List only" button in the Download tab was not creating KENV entries, even though the data was successfully fetched from the blockchain.

## Root Cause
The `addToFileListOnly()` function was not passing `metaTxId` and `metaTxBlockId` to the `executeDownload()` function. Without these parameters, the KENV entry creation logic was skipped.

## Comparison

### Download button (working) - line 16011-16019:
```javascript
await NetworkState.downloadManager.executeDownload(
    kaspaMetadata,
    password,
    {
        onProgress: onProgress,
        metaTxId: kaspaMetadata.metaTx?.txid || null,      // ← Has this!
        metaTxBlockId: kaspaMetadata.metaTx?.blockId || null // ← Has this!
    }
);
```

### Add to File List only button (not working) - line 16345-16350:
```javascript
await NetworkState.downloadManager.executeDownload(metadata, password, {
    addToListOnly: true,
    onProgress: (progress) => { ... }
    // Missing metaTxId and metaTxBlockId!
});
```

## Solution
Added the missing parameters to the `addToFileListOnly()` function:

```javascript
await NetworkState.downloadManager.executeDownload(metadata, password, {
    addToListOnly: true,
    metaTxId: metadata.metaTx?.txid || null,         // Added
    metaTxBlockId: metadata.metaTx?.blockId || null, // Added
    onProgress: (progress) => { ... }
});
```

## Testing
1. Load file metadata via Verify or .kaspa file drop
2. Click "Add to File List only" button
3. File should now appear in the File tab
4. Confirmed: KENV entry is created successfully

## Impact
- Users can now properly add files to their list without downloading
- Feature parity between Download and Add to List functionality
- No changes to existing download behavior

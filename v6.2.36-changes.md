# v6.2.36 Changes - Set Verified Status for Add to File List Only

## Date: 2025-08-21

## Problem
When using "Add to File List only" button, the entry was created with status='pending' (Unverified) even though the metadata had already been fetched and verified.

## Root Cause
The executeDownload function creates KENV entries but doesn't set the status field. Since addMinimalEntry defaults to status='pending', entries remain unverified.

## Solution
Added verification status logic to executeDownload:
- When `addToListOnly` flag is true, set `kenvEntry.status = 'verified'`
- This applies to both TxID verification and .kaspa file loading

## Code Changes
Added at line 10977-10981:
```javascript
// v6.2.36: addToListOnlyの場合は検証済みステータスに設定
if (addToListOnly) {
    kenvEntry.status = 'verified';
    log('[KENV] Entry marked as verified (already fetched metadata)', 'info');
}
```

## Testing
1. Use Verify button to load metadata
2. Click "Add to File List only"
3. Check File tab - entry should show as "Verified" (not "Unverified")
4. Same behavior for .kaspa file loading

## Note
- Regular downloads don't set status (they're not list-only operations)
- File tab's "Add file" function already handles verification separately

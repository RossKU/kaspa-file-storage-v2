# v6.2.46: File tab row selection improvement

## New Features
- **Full Row Selection**: Click anywhere on a file entry row to select/deselect the checkbox
  - Single click on row toggles checkbox selection
  - Double click on row opens entry details
  - Clicking directly on checkbox still works as before

## UI Improvements
- **Visual Feedback**: 
  - Cursor changes to pointer when hovering over rows
  - Hover effect with subtle background color change
  - Active (pressed) state with darker background
  - Selected rows have persistent highlight background
  - User-select disabled to prevent text selection while clicking

## User Experience
- More intuitive file selection - similar to standard file managers
- Larger click target makes selection easier on mobile devices
- Clear visual indication of clickable and selected states

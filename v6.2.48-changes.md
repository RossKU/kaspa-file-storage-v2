# v6.2.48: Directory Builder Intermediate Folder Restoration (A Approach)

## Problem
After restoring from TxID, intermediate folders could not be selected because they were removed by `optimizeEntries()` and not restored to the entries array.

## Solution: A Approach (Entry Restoration)
Implemented `rebuildIntermediateFolders()` method that explicitly adds intermediate folders back to the entries array.

### How it Works
1. **Analyze Paths**: Scans all entries to find required parent paths
2. **Identify Missing**: Checks which intermediate folders are missing
3. **Create Virtual Folders**: Adds missing folders to entries with `virtual: true` flag
4. **Full Selection Support**: All folders (real and virtual) are now in entries array

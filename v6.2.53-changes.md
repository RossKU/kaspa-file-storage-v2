# v6.2.53: Fix KENV entry creation error for MetaTxID-less uploads

## Problem
- When uploading without MetaTxID, KENV entry was not created
- Error: "Assignment to constant variable" prevented KENV entry creation
- Uploaded files had no name or metadata in File tab

## Root Cause
- Line 13990: `totalCost` was declared as `const`
- Line 14068: Attempted to reassign `totalCost` when MetaTxID was disabled
- The error caused the entire KENV entry creation process to be skipped

## Solution
- Changed line 13990 from `const totalCost` to `let totalCost`
- This allows reassignment when calculating actual cost for MetaTxID-less uploads

## Technical Details
- **Before**: `const totalCost = totalChunks * 0.00005 + totalPayloadKB * 0.00001;`
- **After**: `let totalCost = totalChunks * 0.00005 + totalPayloadKB * 0.00001;`

## Impact
- KENV entries are now properly created for all uploads
- File names and metadata are correctly saved
- No more "Assignment to constant variable" errors
- MetaTxID-less uploads work correctly

## Affected Scenarios
- Small file uploads (< 550MB) without MetaTxID
- Files uploaded with "Skip Meta Transaction" option enabled

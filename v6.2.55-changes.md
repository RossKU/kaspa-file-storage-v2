# v6.2.55: Fix multiple XSS vulnerabilities in UTXO and workspace displays

## Security Fixes (5 vulnerabilities fixed)

### UTXO Consolidation (3 fixes)
1. **Processing message** (line 2971)
   - Before: `innerHTML = '⏳ Processing UTXO consolidation...'`
   - After: Safe DOM manipulation with `textContent`

2. **Success message with TxID** (line 3046)
   - Before: `innerHTML = \`✅ Consolidation successful!<br>TxID: ${txid}...\``
   - After: Safe DOM manipulation preventing TxID injection

3. **Error message** (line 3094)
   - Before: `innerHTML = \`❌ Consolidation failed: ${errorMsg}\``
   - After: Safe text node creation preventing error message injection

### Workspace Display (2 fixes)
4. **Workspace folder name** (lines 9978, 9980)
   - Before: `innerHTML = \`<span>📁 ${WorkspaceState.handle.name}</span>\``
   - After: Safe DOM manipulation preventing folder name injection

## Technical Implementation
- Replaced all `innerHTML` with `createElement()` and `textContent`
- Used `document.createTextNode()` for user-controlled data
- Cleared existing content before appending new safe content

## Testing
Test with malicious inputs:
- TxID: `<script>alert('XSS')</script>abcdef`
- Error: `Failed: <img src=x onerror=alert('Hacked')>`
- Folder: `My<script>steal()</script>Folder`

All now display as plain text without executing scripts.

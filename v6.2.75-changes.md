# v6.2.75 Changes - Fix needsMetaTx Flag Management

## 🐛 Critical Bug Fix

Fixed needsMetaTx flag being incorrectly cleared on error, preventing meta-tx auto-resume.

### Problem (From v6.2.74 Testing)

The flag was cleared even when meta-tx failed:
```
[05:59:36.135] needsMetaTxフラグを設定: true
[05:59:36.145] メタTx送信エラー（WebSocket切断）
[05:59:36.682] needsMetaTxフラグをクリア: false  ← ❌ Wrong!
[05:59:40.743] 自動再開条件を満たしません（needsMetaTx: false）
```

### Root Cause

processAndUpload always cleared the flag after calling createAndUploadMetaTx:
```javascript
// Old code (v6.2.73-74)
await createAndUploadMetaTx();
FileState.needsMetaTx = false;  // Always cleared!
```

### Solution

Made createAndUploadMetaTx return success/failure status:

#### 1. Return Value Added (Lines 15108, 15133, 14667, 14783)
```javascript
// Success cases
return true;

// Error case  
return false;
```

#### 2. Conditional Flag Clearing (Line 14449-14459)
```javascript
// New code (v6.2.75)
const metaTxSuccess = await createAndUploadMetaTx();

if (metaTxSuccess) {
    FileState.needsMetaTx = false;  // Only on success
    log('[DEBUG] メタTx成功 - needsMetaTxフラグをクリア: false');
} else {
    log('[DEBUG] メタTxエラー - needsMetaTxフラグを維持: true');
}
```

#### 3. Auto-Resume Path Fixed (Line 8604-8614)
```javascript
const success = await createAndUploadMetaTx();
if (success) {
    FileState.needsMetaTx = false;  // Only clear on success
    FileState.uploadSessionActive = false;
    log('[ConnectionManager] メタTx送信が完了しました');
} else {
    log('[ConnectionManager] メタTx送信失敗 - 次の再試行を待機');
}
```
